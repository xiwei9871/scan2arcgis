## 关键真实观察

1. **A09 几何合并在 U2 上无可验对象**：B2c 已并完所有可安全合并的同色邻对；剩余同色近邻均被真实界线分隔或带风险标记。按任务约定未强行合并，逻辑归组路径实测有效。
2. **文字残影线高度保守是正确行为**：'C-P' 框内 2 条候选线全为压线风险——与 P2 结论一致（U2 注记多压真界线，宁可人工确认）。
3. **窄带恢复的真值验证**：用「先模拟误并再恢复」获得了可量化真值（IoU 0.971），优于无对照的目视判断。
4. 大文档耗时（A33 26s、A01 14.6s）主要为 17k 面规模上 STRtree/覆盖校验的实现成本，非人工点击成本——专业人工可在此基础上叠加思考时间。
