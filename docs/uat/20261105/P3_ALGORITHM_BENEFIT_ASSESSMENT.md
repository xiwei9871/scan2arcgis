# P3 算法改进收益评估（只读分析，未改算法）

范围：T15（OCR 漏检/误识别）+ T16（地质线面算法）。依据：P1 阈值实测、P1.1 真值小样本、P2 合成测试、
P2.1 真实 U2 操作数据（17,047 面 / 606 线 / 219 OCR 记录）。

## 一、OCR 侧（T15）：剩余错误类型与修复成本

| 类型 | 现状证据 | 人工修复成本 | 算法升级价值 |
|---|---|---|---|
| 低置信度错字 | 0.90 阈值送审 160/219=73.1%，审核界面已覆盖 | 每字 1 确认或改字（~5-10s） | **低**——已被审核流覆盖 |
| 高置信度错字（漏审风险） | 真值小样本：自动放行 8 条中 2 条实为错误（25%，探索性） | 靠全量浏览兜底，漏检即错出成果 | **中**——建议提高自动放行的风险规则密度，而非换模型 |
| 地层代号/上下标 | 86 条命中代号规则强制送审；普通英文误判已收紧 | 逐条人工读图改字，成本高（~15-30s/条×86） | **中高**——图例约束识别或代号专用白名单可减少 50%+ 送审量；不必训练新模型 |
| 完全漏检（无分数） | 阈值机制天然不可发现 | 人工补字（框选+输入 ~30-60s/处） | **中**——局部切块放大/多尺度召回比新模型便宜 |
| 竖排/倾斜 | 风险规则已标记送审 | 人工改字+角度 | 低 |

**结论**：OCR 不值得训练新模型。最高性价比 = 图例文字预读约束 + 代号白名单 +
对自动放行样本扩大真值抽查（当前 n=8 仅为探索性证据）。

## 二、线面侧（T16）：仍需人工的类型

| 类型 | U2 实测规模 | 半自动成本（实测） | 算法升级价值 |
|---|---|---|---|
| 文字笔画残影（线） | 'C-P' 框内 2 候选全为压线风险线——U2 注记普遍压界 | 人工逐框确认 3-4 步 | **中**——文字掩膜先验可在识别期避免产生，后验难分 |
| 文字残影面 | 实测 2 面自动归并成功 | 已近全自动 | 低 |
| 同色碎面合并 | U2 无可安全合并邻对（已并完） | 逻辑归组 3 步 | **低**——B2c 合并已充分 |
| 断线端点接合 | ~2px 端点距对实测存在（26/45 等） | 选段+预览+确认 3 步 | 低——半自动已很便宜 |
| 窄带面 | 28 条薄面存在；恢复 IoU 0.971 | 描轴+转面 4 步（实现耗时 26s/17k 面文档） | **中**——识别期「细带保留」规则优于事后描绘 |
| 虚线语义 | 误并后恢复链已验证 | 拆分+删段+图例+编组 ~6 步 | **中高**——识别期保虚线间隔 > 事后拆线 |
| 编组错误 | G52/G62 混组实测存在 | 批量编组 3 步 | 低 |

## 三、B2c 与下一代流水线对比

现有 B2c（`24d2d14`）：U2 全图 16.8s、覆盖合法、空洞 0、同色合并充分。**结构性短板 =
文字/符号与地质要素同期进入分层**，导致 A01/A02/E10/A05/A20 一类残影与语义损失。

候选流水线（图例预读→OCR→文字保护→线追踪→面分区→残差修复）：
- **预期收益**：从源头消除文字残影（A01/A02/E10）、虚线误连（A20）、窄带丢失（A05/A33 一部分）——
  即 P2 中「只能半自动」的那几类。
- **风险**：线追踪在弱对比/交叉处仍可能断（A15 不会自动痊愈）；文字保护掩膜误伤真实界线（新误伤面）；
  图例预读失败则全盘退化。
- **研发成本估计**：文字掩膜+掩膜内重识别 2-4 周；虚线结构感知 1-2 周；细带保真约束 1 周（均为粗估，待评审）。

## 四、建议（按性价比排序）

1. **保留 B2c + 半自动修复为当前交付路线**——P2.1 实测 7/7 场景有可用路径。
2. **先做文字掩膜先验的局部验证**（单区域 A/B，非全图）——它是唯一能同时消掉 A01/A02/E10 三类的手段。
3. 虚线结构感知与图例约束 OCR 并列第二优先（消 A20 + 降代号送审量）。
4. 不立项：OCR 新模型训练、整条流水线重写、A08/A09 自动合并增强（U2 实测已无收益空间）。
5. P3 结论待技术路线评审后实施；本评估**未改任何算法**。

## 五、遗留测量缺口

- 漏检文字数量无真值（需人工标底图文字清单）；
- 虚线误并在 U2 的出现频次未全量统计（仅抽检链 #65/#77/#93）；
- 下一代流水线的收益为推断，未做 A/B 实证——建议 P3 先跑一个 300×300 裁块的对照实验。
