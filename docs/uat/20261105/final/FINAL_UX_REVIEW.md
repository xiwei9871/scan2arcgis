# FINAL_UX_REVIEW — Studio 操作体验评审

## 原则回顾
- 不做大规模视觉重设计；只修真正阻断操作的交互障碍。
- 用户全程在 StitchVector Studio 正常界面操作，不碰 API/脚本/GPKG。

## 本轮已解决的交互障碍

| 障碍 | 解决 |
|---|---|
| 自动合并建议为 0 时只能逐个 Ctrl 点选碎面 | 新增「碎面筛选」：面积/颜色/代号过滤+邻近范围，一键加选（U2 实测 1 击 +26 面）；刷选/套索/框选并存 |
| 断线补接需猜线 ID 再点预览 | 新增「端点接线」工具：点断线端点→青圈标出候选连接端点→点选即预览连接段，含虚线警示 |
| 操作无反馈 | guard() 统一「处理中…」；Studio 管线/导出有进度与结果消息 |
| 侧栏无流程感 | 按 ①-⑨ 工作流编号分区；高级内容（差异查看/线角色/图例/日志）折叠为 details（默认展开） |
| 保存版本被审核门禁误杀 | 版本保存即草稿语义（draft=True）；草稿导出显式复选框+「草稿」标注；正式导出仍被门禁拒绝 |
| beforeunload 干扰测试/内嵌 | `__svNoUnload` 可编程抑制（Studio/自动化用） |

## 遗留 UX 局限（如实记录）

- 侧栏仍长：details 默认展开（为避免遮蔽控件）；用户可手动收起。未做标签页式重构（属大改）。
- 端点接线候选半径固定 60px：大图够用，极端密集区需放大后操作。
- 碎面筛选邻近范围固定 ±120px：无法圈更远碎面时可用框选/套索补足。
- 审核面板逐项跳转在超大待审队列（U2 148 条）下无批量全选确认——保守设计保留，防一键放过。
- 移动文字/加文字工具与选面工具并存，新用户需读工具栏提示行。

## 用户操作量评估

| 任务 | 典型步数 | 对比旧流程 |
|---|---|---|
| 清理一处文字残影 | 3-4 | 旧：逐面逐线点选 10+ |
| 修复碎面簇 | 3-5（含筛选） | 旧：无此能力只能单选 |
| 断线补接 | 2-3 | 旧：补画整段+手动对齐 |
| OCR 审核单条 | 1-2 | — |
| ROI 裁剪导出 | 3 | 旧：无此能力 |
