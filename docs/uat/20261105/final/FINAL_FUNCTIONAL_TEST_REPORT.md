## 交互要求核查

- 功能名中文口语化（选面/框选面/碎面修复刷/端点接线/归为同组/框文字/框ROI）。
- 高级参数折叠：差异查看、线的角色、图例、修改记录收进 `<details open>`（默认展开、可收起，不藏控件）。
- 按钮按流程分区：侧栏 ①显示核验→②选择工具→③已选对象→④编辑与合并→⑥文字残影→⑦ROI→⑧OCR审核→⑨保存。
- 每次操作 msg 行即时显示结果与风险（合并预览冲突%、压线风险、接线端点距、裁剪跨界对象数）。
- 撤销/重做：明显按钮 + ⌘Z/⇧⌘Z。
- 忙碌反馈：所有 API 操作显示「处理中…」；U2 全图实测无长时间无反馈操作（状态查询 <1s，重活如管线处理在 Studio 任务栏显示进度）。
- 草稿保存不被 OCR 审核阻断；正式交付遵守统一门禁（Studio e2e 实证）。
