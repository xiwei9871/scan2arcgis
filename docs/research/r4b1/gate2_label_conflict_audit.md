# R4-B1 Gate 2：窄单元内部标签冲突审计（2026-10-29）

代码：`experiments/R4B1/r4b1_labels.py`、`r4b1_gate2.py`；测试：`tests/r4b1/test_r4b1_labels.py`（3 项通过）。
结果：`experiments/R4B1/gate2/gate2_label_audit.json`，逐实例表 `gate2_instances.csv`。
样本图只保存在本地：`runs/r4b1/gate2/samples/`（每幅训练图 3 个最窄实例，共 30 张；四栏依次为原图、v2 软目标、HARD 规则像素（红，压在墨线上为紫）、SAFE 规则像素（绿），墨线为蓝）。
只读取 10 幅训练图的标签和原图；没有读取验证图，没有用到任何模型输出，也没有训练。

## 结论：**发现严重标签矛盾，按任务书停止，不进入 B1 训练**

- R4-B0.1 提议的规则（HARD：窄单元内所有非 UNIT_BOUNDARY 像素设为目标 0、权重 1）**与现有正样本直接冲突**：它触及的像素中 78% 原本是软边界正标签，72% 落在印刷墨线 1 px 以内。
- 按优先级规则 `IGNORE_EVAL > 真实边界保护 > 可靠内部负监督 > 原有监督` 构造的 SAFE 规则没有冲突，但**覆盖严重不足**：3–6 px 地层可用的内部负样本为 0。
- 更根本的发现是：**在现有 v2 目标下，3–6 px 地层"内部被预测成边界"本身就是损失函数的最优解。** 问题出在边界目标的定义上，模型只是学到了这个定义。

## 1. 两条规则

| 规则 | 定义 |
|---|---|
| HARD（R4-B0.1 提议） | 内切宽度 < 10 px 的实例中，所有不属于 UNIT_BOUNDARY 的像素：目标 0，权重 1 |
| SAFE（按优先级） | 同一范围内，再排除 d ≤ 2 px（软正标签带）、墨线 1 px 以内、IGNORE_EVAL；剩下的像素权重提高到 1。v2 的目标值本来就是 0，不改动任何目标值 |

## 2. 逐宽度统计（10 幅训练图）

| 指标 | 3–6 px | 6–10 px |
|---|---|---|
| 实例数 | 43 | 256 |
| UNIT_BOUNDARY 占实例面积 | **52%** | 30% |
| HARD 规则触及的像素（占面积） | 14,275（47%） | 104,335（69%） |
| 其中原本是软正标签（d ≤ 2，**直接冲突**） | **97.9%** | **71.3%** |
| 其中原本是 2–4 px 低权重负样本（只是加大权重） | 2.1% | 27.9% |
| 其中在墨线 1 px / 2 px 以内 | 85.4% / **97.7%** | 70.1% / 91.8% |
| 这些像素在 v2 下的损失最优概率均值 | 0.795 | 0.526 |
| SAFE 规则像素（占面积） | **115（0.4%）** | 13,964（9.3%） |
| 有任何 SAFE 像素的实例 | 30% | 95% |
| SAFE 像素可用的实例（≥ 20 px 且 ≥ 实例面积 10%） | **0%** | 43% |

10–20 px 和 ≥ 20 px 的实例不受任何影响。10 幅图上逐像素核对：窄单元以外的权重图与 v2 完全相同，目标图没有被改写。

**合计：** HARD 规则共触及 172,550 px，其中 134,314 px（78%）与软正标签冲突，123,940 px（72%）在墨线 1 px 内。SAFE 规则共 18,403 px，只相当于 v2 总监督权重的 0.018%。

## 3. 对任务书六个问题的回答

1. **新负样本是否与 UNIT_BOUNDARY 正样本冲突？** HARD 规则不直接覆盖 UNIT_BOUNDARY 像素，但覆盖软正标签带：3–6 px 中 98%，6–10 px 中 71%。这正是 v2 设计里"边界两侧 2 px 为正"的区域，属于直接矛盾。
2. **哪些原来是软正标签，哪些是低权重负样本？** 见上表第 4、5 行。3–6 px 的内部几乎全部（98%）是软正标签。
3. **配准误差 1–2 px 下，内部负样本是否会压到真实印刷线？** 会。HARD 像素 92–98% 在墨线 2 px 以内。一条 3–6 px 的地层，两条印刷界线之间几乎没有"离线 2 px 以上"的像素。
4. **3–6 px 地层有多少可靠的内部监督像素？** 43 个实例合计 115 px，平均每个不到 3 px，没有一个实例达到可用标准。**3–6 px 没有足够可靠的非边界像素，按任务书不得强制制造负标签。**
5. **大单元和普通地层的监督是否不变？** 是。窄单元以外的像素在 10 幅图上逐像素一致。
6. **M2 距离头的目标是否与新监督矛盾？** 不矛盾。两条规则都不改距离目标；SAFE 像素的官方距离均值为 2.75–2.96 px，与"非边界"一致。

## 4. 理论目标诊断：v2 的最优解本身就淹没窄地层

v2 损失（BCE，pos_weight 4，软目标 exp(−d²/2)，d ≤ 2 px）的逐点最优概率为 p\* = 4t/(3t+1)。p\* > 0.5 当且仅当 d < 1.79 px。

| 宽度 | 实例像素中 p\* > 0.5 的比例 | 至少 90% 像素 p\* > 0.5 的实例 |
|---|---|---|
| 3–6 px | **94.7%** | **69.8%** |
| 6–10 px | 68.1% | 2.3% |
| 10–20 px | 42.2% | 0% |

- **3–6 px：** 即使模型完美拟合 v2 目标，70% 的实例也会有 90% 以上像素被判为边界。R4-B0 在验证图上观察到的比例是 88–91%（不同图幅，只作方向对照）。也就是说，这一组的"内部淹没"主要来自**目标定义**：UNIT_BOUNDARY 在交界两侧各标一个像素，再加上 2 px 的软正标签带，一条 5 px 的地层从两侧被正标签覆盖到中间。
- **6–10 px：** 理论最优只让 2.3% 的实例被淹没，R4-B0 在验证图上观察到的却是 79–86%。这一组的问题主要来自**模型输出比目标更宽**（与 R4-A2.1 P0 的结论一致），而不是目标定义。

因此，R4-B1 原计划用"内部负监督"解决两组问题，这条路行不通：3–6 px 没有可用的负样本，6–10 px 的 SAFE 像素虽然有，但只占监督总量的 0.018%，不加权的话影响可以忽略，加权则需要选一个新的权重参数。

## 5. 停止决定

任务书规定："Gate 1–2 如果发现训练标签存在严重矛盾，则先报告并停止训练"。HARD 规则 78% 的像素与正标签冲突，SAFE 规则在 3–6 px 没有覆盖，属于这一情况。**Gate 3–7 没有执行**：没有选新测试图，没有冻结 B1 配置，没有训练。

## 6. 可选的下一步（需要你决定）

1. **只修采样，作为单因素实验：** 用 Gate 1 的内部锚点替换端点锚点，监督不变。不存在标签冲突，但 Gate 1 预计收益很小（6–20 px 图块覆盖只提高约 1 个百分点），并且不解决 3–6 px 的问题。
2. **修改边界目标的定义：** 例如把正样本改为交界的单侧 1 px，或收窄软标签带。这会改变所有单元的理论最优解，是比"内部负监督"更大的改动。在训练前，可以先用训练图标签算出新目标下各宽度组的理论最优覆盖率和种子可得性，作为可证伪的诊断；这一步不需要训练，成本几分钟。
3. **独立的内部/区域预测头：** 让模型额外输出"是否在单元内部"，不再从边界概率推出区域。这需要改网络结构，属于后续阶段的工作。
