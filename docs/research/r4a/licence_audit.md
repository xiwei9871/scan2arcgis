## 2. 未解决的问题

1. **200 dpi 原图属于哪一类：** 原图从网站下载，像是"网站内容"（可改编、可商用）；但它是 1:5 万印刷地质图的复制品，而印刷许可表把这类图定为 CC BY-ND。条款没有写明哪一条优先。
2. **矢量数据：** 矢量数据是网站公开的数字数据，更接近政府标准利用规约的适用范围，但也没有单独写明。
3. **训练是否算"改编"：** 按 CC BY-ND，在内部训练模型、不发布改编作品是否允许，条款没有直接回答。
4. **底图权利：** 原图中的地形底图可能来自国土地理院，权利人不是 GSJ。

## 3. 项目负责人的决定（2026-10-28）

项目负责人确认：**本项目目前没有任何商业用途**，同意按非商业研究先开展训练。

为了在最严格的一种解读（CC BY-ND）下也不出问题，本轮自行加上以下限制：

- 原图、官方矢量、由它们生成的图块和标签，只保存在本地，不提交、不上传、不再分发。
- 用 GSJ 数据训练的模型权重只保存在本地，不发布。
- 仓库只提交代码、配置、数据清单（来源 URL、SHA-256）、聚合指标，以及不含原图内容的图表。
- 所有引用都注明出处：图幅名、著者、产综研地质调查综合中心、页面 URL。
- **任何商业使用之前**，必须先取得 GSJ（出版室 `publish@gsj.jp`）的书面确认；地形底图部分视情况另询国土地理院。
