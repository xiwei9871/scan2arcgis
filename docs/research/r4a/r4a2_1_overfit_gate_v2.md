## 3. 失败原因（只分析已有输出，未新跑训练）

- **不是实现错误。** 判定项按冻结文件实现：在权重 > 0 的像素上计算不加权平均 |p − p\*|。同一个量按损失权重加权后为 0.052（M1）和 0.038（M2），这里只作说明，不改变判定。
- **到第 300 步还没收敛。** 偏差逐检查点下降：M1 0.279 → 0.215 → 0.168 → 0.127 → 0.098 → 0.079，M2 0.295 → … → 0.056。冻结前我没有估计 300 步能否把偏差降到 0.05，这是门槛设计的失误。
- **剩余偏差集中在新加监督的 2–4 px 带。** 该带权重只有 0.1，最优解是 0，但第 300 步的平均偏差是 0.29（M1）和 0.20（M2），中位概率 0.28 和 0.17。4–8 px 带（权重 0.3）分别是 0.13 和 0.09。>8 px 和 0–2 px 带的偏差为 0.03–0.06。
- **v2 监督确实约束了带宽。** p>0.5 时，带宽从 8.7–9.4 降到 5.3–5.4，F1@1px 从 0.60–0.64 升到 0.86–0.87，2–8 px 带内的概率不再停在约 0.45。代价是，低权重下这个带在 300 步内拟合得慢。
- **定位已经达标。** 在 p>0.8 下，中心线误差 0.20–0.23 px，F1@1/2/3 ≥ 0.995，带宽 3.9（理论最优 4.04）。

结论：v2 模型学会了定位细线，输出宽度也受到了控制。没通过的原因是：门槛要求的目标拟合精度在 300 步内达不到，而低权重带收敛慢。按任务书，我不改门槛、不加步数、不调权重。
