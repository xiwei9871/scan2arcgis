# 置信度与人工介入设计（S2A-R1 任务 D）

本轮所有分数均为 **UNCALIBRATED**，只用于排序与定位，不代表正确概率。决策策略 `r1_poc_uncalibrated_v0`（`src/scan2arcgis/confidence/decide.py`）**从不输出 AUTO_ACCEPT**，由 D0 校验规则 V3 与测试 `test_decision_policy_never_auto_accepts` 强制。

## 1. 处理流程

```
识别 → 硬约束检查 ──FAIL──> BLOCKED
          │PASS
          ▼
     软信号（未校准） ──> 排序 ──> AUTO_RETRY（换识别器变体重跑）
                               └─> HUMAN_REVIEW（按风险排序的区域队列）
                               └─> NONE（暂不处理，等待校准后才可能 AUTO_ACCEPT）
```

## 2. 各要素的可靠性信号

| 要素 | 本轮已实现信号 | 计划中的信号 | 硬约束（本轮） |
|---|---|---|---|
| 地层面 | 区域平均分类边际（top1−top2）、低边际像素比例、面积、紧凑度 | 自训练前后类别是否稳定；多识别器一致性；与图例色差；面内注记代号 OCR 是否与类别一致（独立证据） | 几何有效；类别存在于图例 |
| 接触线 | 两侧面中较低的平均边际 | 与原图墨迹的重合度（独立于颜色分类） | 几何有效 |
| 断层 | 骨架长度 × 延伸度 | 线检测模型概率；与接触线的拓扑关系 | 几何有效 |
| 图例 | 色块均匀度 | OCR 置信度；色块数与图面颜色簇数之比 | — |
| 整图 | 平均边际、低边际比例 | 与已有图式的分布距离（OOD） | 图例解析失败 → 整图 BLOCKED |

**分层置信度**：每个要素记录 `raw_score`、`quality_signals`（全部原始信号）、`hard_checks` 与 `decision`。一个地层面可以同时有类别信号（边际）、边界信号（接触线两侧边际）和拓扑状态（硬约束），见导出的 GeoPackage。

## 3. 本轮概念验证结果

### 3.1 区域信号能否区分对错（合成，15 张，对象级）

| 识别器 | 区域平均边际 → 对象正确 的 AUROC |
|---|---|
| 图例最近色 | 0.786 [0.70, 0.87] |
| 图例 RF | 0.875 [0.81, 0.93] |
| 图例 RF + 自训练 | 0.827 [0.76, 0.89] (n=14) |

AUROC 明显高于 0.5，说明未校准的边际**有排序价值**。但这不是概率，也没有证明在真实图上同样有效。

### 3.2 能否把人工检查限制在局部区域（合成）

把图面划分为 64×64 像素的块，按风险信号排序，统计前 k% 的块中包含多少比例的错误像素：

| 识别器 | 前 10% 块 | 前 20% 块 | 随机期望 |
|---|---|---|---|
| 图例最近色 | 0.185 | 0.313 | 0.10 / 0.20 |
| 图例 RF + 自训练 | 0.208 [0.17, 0.25] | 0.358 [0.30, 0.42] | 0.10 / 0.20 |

**结论**：比随机好约 1.8–2 倍，但远未达到“少量区域就能覆盖大部分错误”的程度。主要原因（叠加图观察）：大量错误是**高置信度的系统性错误**，例如晕渲区域整片误分类，边际并不低。这正是任务书提到的“高置信但客观错误”，需要独立证据和抽检来发现，单靠分类器自身的边际不够。

### 3.3 AUTO_RETRY 能否自动选出更好的变体

两个变体（基础特征 / 色度不变特征），按无监督标准“整图平均边际更高者”自动选择：

| | 平均 mIoU（15 张合成） |
|---|---|
| 只用基础变体 | 0.8742 |
| 只用色度不变变体 | 0.9071 |
| 自动选择 | 0.9006 |
| 理想选择（已知真值） | 0.9265 |

自动选择与理想选择一致 10/15 次。自动重试有收益，但选择标准本身也未校准。

### 3.4 真实图上的决策分布（未校准，仅供观察）

| 地图 | 面数 | HUMAN_REVIEW | AUTO_RETRY | NONE | 复核区域（前 10% 块） |
|---|---|---|---|---|---|
| gm2 ROI | 250 | 98 | 30 | 122 | 见 GeoPackage `review_regions` 图层 |
| u1 | 96 | 22 | 27 | 47 | 同上 |
| u3 | 223 | 2 | 18 | 203 | 同上 |

u3 只有 2 个 HUMAN_REVIEW，但叠加图显示仍有可见错误，再次说明未校准信号会漏掉高置信错误。

## 4. 防止高置信错误与虚假一致

1. **独立证据**：地层面内的注记代号（OCR）与分类结果比对；接触线与原图墨迹比对。它们与颜色分类器的特征不同源。
2. **一致性要看错误相关性**：同一颜色特征训练的两个分类器即使一致也不算独立证据。校准阶段计算各信号**错误之间**的相关性，只把错误不相关的信号作为独立证据。
3. **随机抽检**：自动接受的结果按图幅随机抽检（`review_sampling=random_audit`），只用抽检估计自动接受的实际错误率。
4. **图幅级 OOD**：新图式下整图降级，不允许自动接受。

## 5. 如何校准（下一阶段）

1. 在 D0 的 `calib` 切分上，为每个要素收集信号与对错标签。
2. 训练误差预测模型（梯度提升树），输入为全部 `quality_signals`，再用 isotonic 校准。
3. 在 `holdout` 上画 Risk–Coverage 曲线，置信区间按图幅 bootstrap。
4. 由业务方给定风险上限 α，反推每类要素的自动接受阈值；没有 α 之前不启用 AUTO_ACCEPT。

样本量提示：要证明“自动接受部分错误率不超过 5%”，零错误时至少需要约 60 个独立的被接受对象，并且应来自多张图幅。
