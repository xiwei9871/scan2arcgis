# 下一阶段技术路线建议（S2A-R1）

## 1. 结论

**路线：图例驱动的混合识别（传统 + 学习）为主干，深度模型按要素逐个引入，每次引入必须在同一评估集上胜过当前主干。**

本轮证据支持的判断：

1. 旧颜色匹配和界线规则已不值得继续调参。同一输入下，新的“图例样本训练 + 图面自训练”分类器在合成基准上面 mIoU 0.874 vs 0.609、全部线 F1 0.831 vs 0.092；在 4 张真实图上旧方法 36–98% 面积不出结果，新方法能完整分区。
2. 接触界线应由面拓扑导出，不再单独检测。导出的接触线 F1 0.827，且与面结果天然一致。
3. 新方法在真实图上的质量**远低于**合成基准（gm2 draft 参考：平均最佳 IoU 0.233–0.254），主要问题是近色类别混淆、注记和符号造成的碎片。这是下一阶段的主攻方向。
4. SAM 2.1-tiny 可以在 CPU 上运行，但作为自动精修收益不显著；更适合放在复核环节做“点一下重分割”。
5. 断层（独立线要素）是当前最弱的要素，规则候选无法满足要求，需要专门的线检测模型。

## 2. 推荐的自动化流程

```
1 图幅解析     自动定位地图区与图例区（本轮：人工给 ROI；R2：版面检测）
2 图例理解     色块检测（已实现）→ 代号/名称 OCR（R2：PaddleOCR 中文）→ 图例字典
3 面要素       逐图分类器（基础 + 色度不变两个变体，AUTO_RETRY 自动选择）
               → 注记/符号移除 → 近色类别消歧（面内代号 OCR 作独立证据）
4 线要素       接触线 = 面公共边；断层 = 线检测模型（R2）+ 拓扑约束
5 点要素       图例符号模板 / 检测（R3，复用旧矿种裁片）
6 拓扑重建     分区 → 多边形 → 公共边；硬约束检查
7 质量决策     软信号 → 误差预测模型 → 校准（需 calib 切分）→ AUTO_ACCEPT / RETRY / REVIEW / BLOCKED
8 导出         GeoPackage（像素空间，未配准）；配准模块后续接入
```

## 3. 下一轮实验（R2）

| 编号 | 实验 | 假设 | 输入 | 成功标准 | 失败后决策 |
|---|---|---|---|---|---|
| R2-1 | 真实图局部标注 L1 | 没有真实参考就无法判断真实进步 | gm2、u2、u3 各 3–5 个 ROI，地质人员标注面与线（含代号） | 指标置信区间可用于比较方法 | — |
| R2-2 | 近色消歧与碎片清理 | 面内代号 OCR + 类别合并可显著减少碎片 | R2-1 数据 | 对象 F1 在 L1 上较本轮提升且区间不重叠 | 改用分割模型（SAM 自动掩码 + 图例分类） |
| R2-3 | 断层线检测模型 | 在合成 + 少量真实线标注上训练的 U-Net 类模型显著优于规则候选 | 合成线数据（本轮生成器可扩展）+ R2-1 线标注 | 真实 L1 上断层 F1 明显高于规则候选 | 改用交互式线跟踪（复核环节） |
| R2-4 | 中文图例 OCR | PaddleOCR 能读出大部分图例代号与名称 | 4 张图的图例区 | 代号字符准确率可测 | VLM 图例解析对比 |
| R2-5 | 校准起步 | 误差预测模型在独立图幅上 AUROC 高于单一边际 | R2-1 数据按图幅切分 | Risk–Coverage 曲线可画出 | 增加图幅 |
| R2-6 | 人工工时对比 | 复核模式比纯人工数字化省时 | 1–2 张图，同一操作员两种方式各做一次 | 有计时数据 | — |

## 4. 资源需求

- 一名地质人员 5–8 个工作日做 R2-1 标注。
- 一台带 GPU 的机器（训练线检测模型、运行 uncharted-ta1 对比）；推理仍以 CPU 为目标。
- 更多中国地质图图幅（不同比例尺、年代、出版单位），尤其有已有数字化矢量可作真值的图幅。
