# R4-C0.1 Gate 3：R4-C1 研究方案（提议，未执行）（2026-10-30）

依据：R4-C0 Gate 1–5、R4-C0.1 Gate 0（`ee867fd`）、Gate 1–2（`03261e6`）。本轮没有修改 τ，没有重新评价，没有访问新图。

## 1. 要解决的四个问题及证据

| 问题 | 证据 |
|---|---|
| τ 在样本内预测上选定，导致新图上合并偏保守 | 训练图上过分割 0.034；15076 上碎片类失败从 87 增加到 120 |

## 2. 改动分两类

### A. 工程完善（不改变算法，不需要新的预注册，但必须单独提交、回归测试，并在已暴露的图上确认结果不变）

1. **导出范围改用由图像推出的掩膜**（R4-C0.1 Gate 0 的发现）。用 `r4a2_2_m0.content_mask` 替换 `ignore.npy`。对所有方法都适用。验收：预测区域图逐像素不变，只是导出范围不同；报告面积差异。
2. **区域图实现的性能与可读性。** 只在合并序列逐项相同的前提下允许修改，可用 R4-C0 的冻结输出做回归。
3. **验收工具：** 完善 QA 页面，例如加上 GeoPackage 图层切换、按类别筛选。

### B. 算法变化（每一项都需要新的预注册、全新测试图，并且只运行一次）

按优先级排列：

**B1. 解决 τ 的样本内偏差（最高优先级）。**
- **做法：** 不再用训练图的样本内预测选 τ。可选两种方式，预注册时二选一：
  - (a) 留一交叉验证：对 10 幅训练图，各训练一个"不含该图"的 B2，用留出图的预测选 τ。需要 10 次训练，约 18 小时，成本高。
  - (b) 用开发图 15023、15041 选 τ。这两幅图本来就参与了 B2 检查点选择，不增加新的暴露。成本几分钟。
- **建议选 (b)，** 并明确记录"τ 在开发图上选定，开发图不再作为评价依据"。
- **证伪：** 在两幅全新测试图上，过分割增加 ≤ 0.03，且召回增益仍 ≥ +0.03。

**B2. 伪碎片清理（只在 B1 之后做）。**
- **做法：** 对合并后小于 200 px 的区域，再做一轮合并，规则在预注册中只定一种：例如"该区域与邻居的共享边界中位强度低于 τ₂，且区域内没有足够强的闭合边界"。
- **要求：** 不能按面积一刀切。Gate 2 显示，小于 200 px 的区域中有 199 / 284 个是真实小地质实例。
- **证伪：** 伪碎片减少至少 50%，而小实例召回下降不超过 0.01。

**B3. 外观的条件使用。**
- **做法：** 只在"当前图幅内颜色可分"时才启用颜色代价，例如按区域颜色的整体离散度判断。判据和阈值只能在训练图上确定。
- **说明：** 目前只有两幅图的证据，且结论相反。这一项优先级低，不应在 B1、B2 之前做。

**B4. 改善初始区域（研究性，成本最高）。**
- **做法：** 针对已混合的 6–10 px 实例，研究多种过分割的并集、更小的 h 值，或沿 B2 边概率的方向信息切分（接近 OWT 的做法）。
- **前提：** 先在训练图上测 Oracle A 的上限变化。只有上限提高到值得投入时，才进入完整流程。

## 3. 补做的归因对照（不属于新算法，但需要预注册）

**同一 B2 预测下的消融：** "B2 边概率 + hybrid 种子分水岭"对比 "B2 边概率 + RAG"。这可以把 R4-C0 的 +0.16 到 +0.20 拆成"预测来源"和"重建方式"两部分。

- 在已暴露的图（15023、15041、13014、15076）上运行即可，因为它不用来选择任何方案，只用于解释。
- 成本：几分钟。

## 4. 建议的执行顺序

1. 工程完善 A1（导出掩膜）；同时做第 3 节的归因消融。
2. 人工验收：用 R4-C0.1 的验收包和记录表，由 GIS 操作人员在 13014、15076 上记录实际修图时间。
3. 根据人工验收结果决定是否做 B1。如果实测表明伪碎片清理成本很低，B2 的优先级可以降低。
4. B1 →（B2）→ 在两幅全新测试图上做一次评价。
5. B3、B4 暂缓。

## 5. 不建议现在做的事

- 不在 13014、15076 上调 τ，再用这两幅图报告结果。
- 不扩大训练数据，也不训练新模型，直到重建流程稳定。
- 不用面积阈值一刀切地删除小区域。
