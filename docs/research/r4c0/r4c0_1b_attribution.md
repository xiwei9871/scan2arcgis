# R4-C0.1b Work 2：同源归因与勘误（2026-10-30）

代码：`experiments/R4C0/r4c0_1b_attribution.py`。结果：`experiments/R4C0/r4c0_1b/attribution.json`。
图幅 13014、15076 在 R4-C0 中已经暴露，这里只做归因诊断，不是新的测试。没有训练，没有改 τ。

## 1. 勘误

R4-C0.1 Gate 0 审计报告（`docs/research/r4c0/r4c0_1_gate0_audit.md`，提交 `ee867fd`）第 3 节写道："在 13014、15076 上用的是同一份 B2 边概率：R4-B2 的硬阈值连通分量重建只得到 0.058 / 0.111"。**这是错的。** 0.058 和 0.111 分别是 R4-B2 Stage 4 在 **13015** 和 **14030** 上的结果，不是 13014、15076。

13014、15076 上用同一份 B2 预测做硬阈值连通分量，正确结果是 **0.117** 和 **0.072**（见下表）。结论方向不变：在同一份预测下，重建方式决定了大部分结果。原报告保持不变，以本勘误为准。

## 2. 同源对照

所有以 B2 开头的行，以及 RAG，都使用同一份已保存的 B2 预测（`runs/r4c0/pred_test/<图>/B2`）。B2_TERRAIN_M2SEEDS 与 M2_hybrid 使用**同一组**冻结的 hybrid 种子（来自 M2 距离头），只是地形不同。

| 方法 | 地形 / 证据 | 重建方式 | 13014 小实例召回 / 过分割 / 区域数 | 15076 |
|---|---|---|---|---|
| M2_hybrid | M2 距离场 | hybrid 种子分水岭 | 0.603 / 0.035 / 1027 | 0.552 / 0.081 / 1795 |
| B2_HARD_CC | B2 边概率 | 硬阈值连通分量 | **0.117** / 0.006 / 28531 | **0.072** / 0.025 / 35615 |
| B2_TERRAIN_M2SEEDS | B2 边强度 | 同一组 hybrid 种子分水岭 | 0.602 / 0.031 / 1027 | 0.561 / 0.082 / 1795 |
| B2_OVERSEG_NO_MERGE | B2 边强度 | 只过分割，不合并 | 0.498 / 0.457 / 8888 | 0.485 / 0.449 / 12015 |
| **RAG_BOUNDARY_ONLY** | B2 边强度 | 过分割 + 区域图合并 | **0.800** / 0.053 / 1777 | **0.716** / 0.114 / 3030 |

## 3. 分解

| 分量 | 13014 | 15076 |
|---|---|---|
| 地形来源（同一组种子，B2 边 − M2 距离） | **−0.001** | **+0.010** |
| 重建方式（同一份 B2，RAG − 种子分水岭） | **+0.197** | **+0.154** |
| 合计（RAG − M2_hybrid） | +0.196 | +0.164 |
| RAG − 硬阈值连通分量（同一份 B2） | +0.682 | +0.643 |

**结论：** R4-C0 相对 M2_hybrid 的提升几乎全部来自重建方式，即"过分割 + 按整条共享边界的中位强度合并"，而不是换用了 B2 的边概率。把 M2 距离场换成 B2 边概率、种子保持不变，召回只变化 −0.001 到 +0.010。这回答了你指出的混杂问题：+0.16 到 +0.20 可以归因于合并机制。

两点补充：
- **种子是瓶颈。** 同样的 B2 地形，用 hybrid 种子只有 0.60 / 0.56，用 RAG 合并有 0.80 / 0.72。这与 R4-B0 Gate 3 的结论一致：种子规则对窄单元不产生种子。
- **只过分割不合并**的召回是 0.50 / 0.49，过分割 0.45。合并步骤在"降低过分割"的同时把召回提高了 0.23–0.30。
