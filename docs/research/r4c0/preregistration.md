## 口径更正

1. R4-B0 Gate 3 中的 0.823 / 0.783（M1 概率作地形）和 0.740 / 0.714（M2 距离）都使用了**由官方实例推出的理想种子**，是 Oracle 上限，不是可部署的自主成绩。路线报告中"只换种子就能从 0.596 提高到约 0.82"的说法夸大了，它只说明有改进空间。

## 文献依据与简化

- **OWT-UCM（Arbeláez 2011）：** 从轮廓得到初始区域，再按边界强度构造层级。本研究用的是**简化、无方向**的版本：在边界图上做分水岭，再按共享边界上像素对强度的**中位数**贪心合并。它**不是** OWT-UCM 的复现。选中位数而不是平均值，是为了减少少数强或弱像素对整条边界的污染。
- **Superpixel Benchmark（Stutz 等）：** 使用 ASA 和欠分割误差 UE 的定义，只作为区域质量指标报告。

## 输入

- **训练图：** 10 幅冻结训练图，只用于 Gate 1、2。需要用冻结的 M1 / M2 / B2 权重在这 10 幅图上做一次推理。**这些是样本内预测**，比新图上干净，所以 Oracle 和选出的阈值可能偏乐观；Gate 3 在留出图上检验这一点。

- **回顾性对照：** 14030、13015。已经看过 M2_hybrid 和 B2 的结果，只作对照，不作为独立测试。
- **推理时只读取模型输出和 RGB 图像。** 标签只在 Oracle 和评价代码中读取。

## 三种候选与统一的过分割方法

| 候选 | 像素强度 b | 像素对强度 |
|---|---|---|
| M1 | M1 边界概率 | max(b_p, b_q) |
| M2 | M2 边界头概率（不用距离头） | max(b_p, b_q) |
| B2 | 与该像素相邻的各像素对边概率的最大值 | 该像素对自己的边概率 |

过分割（三种候选相同，`r4c0_rag.overseg`）：q = round(255 b)；种子 = q 的 h-minima（h = 13，即概率 0.05）的四连通分量；在全图上做四连通分水岭。没有面积阈值，也没有其他参数。

## 区域邻接图与合并

- **节点：** 初始区域。**边：** 共享至少一对四邻接像素的两个区域。每条边记录共享像素对强度的 64 档直方图；每个区域记录面积，以及非墨线像素的 Lab 颜色总和与计数。
- **合并：** 贪心、确定性。每次合并代价最低的一对相邻区域；合并后直方图和颜色相加，受影响的边重新计算代价。
  - `RAG_BOUNDARY_ONLY`：代价 = 共享边界上像素对强度的中位数。
  - `RAG_BOUNDARY_APPEARANCE`：代价 = 中位数 + λ × min(区域平均 Lab 色差 / 30, 1)。两种方案使用相同的初始区域。
  - 颜色只从当前图像计算。墨线用 black-hat 9 px > 40 再外扩 1 px 判定，这一规则只读图像。不使用官方类别、图例—单元对应或测试标签。
  - 弹出的代价第一次超过 τ 时停止合并。

## Gate 1：初始过分割可行性（只用 10 幅训练图）

- **报告项：**
  - 区域数和面积；
  - 区域邻接图的节点数和边数；
  - 时间和峰值内存；
  - ASA、UE；
  - 两类 Oracle 的分宽度召回；
  - 已在初始区域中混合的小实例比例；
  - 大实例被切成的块数。
- **Oracle A（乐观）：** 每个实例单独取初始区域并集所能达到的最佳 IoU。**忽略**互斥（同一个区域可以给多个实例用）和并集的连通性。
- **Oracle B（可实现的真值辅助合并）：** 每个初始区域分给其多数实例，同一实例的相邻区域合并。区域不可再分，每个区域只用一次，并集通过区域图连通。
- **混合：** Oracle A 的最佳 IoU < 0.5。
- **合格条件：** 训练图合并后，6–20 px 组的 Oracle A 召回 ≥ 0.90；每幅图峰值内存 ≤ 12 GB；每幅图用时（过分割 + 建图 + 完整合并序列）≤ 15 分钟；每幅图初始区域 ≤ 400,000 个。
- **停止条件：**
  - 没有任何候选合格：路线一停止，报告限制。
  - 某个候选在 M4 16 GB 上算不动：该候选取消资格，不重新调参。
  - 所有合格候选的 Oracle B 在 6–20 px 组都 < 0.80：说明有效合并无法逼近上限，停止。
- **3–6 px 单独报告**，不作为停止或通过的理由。

## Gate 2：冻结

- **选候选：** 合格候选中，训练图 6–20 px 组 Oracle B 最高的一个；差距 < 0.005 时选初始区域少的。
- **τ 网格：** 0.05–0.95，步长 0.05。**λ 网格：** {0.1, 0.25, 0.5, 1.0}。
- **目标：** 10 幅训练图合并后的小实例召回，约束为过分割 ≤ 0.10；差距 < 0.002 时选较小的 τ，再选较小的 λ。
- `RAG_BOUNDARY_ONLY` 只选 τ；`RAG_BOUNDARY_APPEARANCE` 联合选 (τ, λ)。
- 选好后提交冻结，再进入 Gate 3。

## Gate 3：开发验证（15023、15041；14030、13015 只作回顾）

- **比较：** M2_hybrid、RAG_BOUNDARY_ONLY、RAG_BOUNDARY_APPEARANCE。
- **报告：**
  - 小实例召回，以及 6–10、10–20 px 召回（3–6 px 单独列出）；
  - 合并、过分割、欠分割、区域数；
  - 大实例召回；
  - 边界 F1；
  - GIS 导出 9 项检查。
- **失败分解：**
  - **INITIAL_MIXED：** Oracle A < 0.5；
  - **MERGE_ERROR：** 不是 INITIAL_MIXED，且最佳区域还包含另一个实例 50% 以上的面积；
  - **UNDER_MERGE_FRAGMENTS：** 不是 INITIAL_MIXED，且没有一个区域包含该实例 50% 以上的面积；
  - **OTHER：** 其余情况。
- **外观效果：**
  - **PREVENTED_MERGE：** 外观版恢复了，纯边界版是 MERGE_ERROR；
  - **CAUSED_SPLIT：** 纯边界版恢复了，外观版是 UNDER_MERGE_FRAGMENTS。
- **灾难性合并：** 最大预测区域面积 > 最大官方实例面积的 1.5 倍。
- **通过条件：** 至少一种 RAG 方案在两幅开发图上都满足：
  - 小实例召回 ≥ M2_hybrid + 0.03；
  - 过分割增加 ≤ 0.03；
  - 大实例召回下降 ≤ 0.05；
  - 没有灾难性合并。

  否则停止，不消耗新的独立测试图。
