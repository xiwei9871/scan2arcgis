## 五个问题

1. **不训练的区域级重建是否真正优于 M2_hybrid？** 在召回上是，而且四幅留出图（2 幅开发、2 幅新图）一致，回顾性对照图也一致。在预注册的综合标准上不是，因为过分割略超上限。
2. **改进来自初始区域还是合并机制？** 来自合并机制。初始区域混合造成的失败数与 M2_hybrid 几乎相同（13014 上都是 43 个，15076 上是 96 对 97），而合并错误减少了 60–70%。这正是对你核心问题的回答：**当两个单元之间有一段界线没有被检测到时，按整条共享边界的中位强度合并，确实能把它们保持为两个独立的面。**
3. **哪些 6–20 px 单元被保护住了？** 6–10 px 组收益最大：13014 从 0.096 到 0.798，15076 从 0.085 到 0.459。10–20 px 组提高 0.06–0.16。逐实例结果在各 Gate 的 JSON 中。3–6 px 组也从 0 提高到 0.15–0.48，但样本小、波动大。
4. **外观是否提供了增量信息？** 部分有。15076 上增益 +0.025（置信区间不含 0），13014 上 −0.007（区间含 0）。目前只能说"在部分图上有用"。
5. **下一阶段做什么？** 见下节。

## 剩余瓶颈

- **合并不足：** 在新图上 τ 偏保守，碎片类失败增加，导致过分割超限。原因很可能是 τ 在训练图的样本内预测上选定。
- **初始区域混合：** 占剩余失败的 23–28%，合并无法补救，要靠更好的边界预测或过分割方法。
- **碎区：** 每幅图有 300–600 个小于 50 px 的区域，GIS 使用时需要处理。
