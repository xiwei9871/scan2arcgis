## 3. 失败分解（小实例失败数）

| | 15023：M2h / RAG_B / RAG_A | 15041：M2h / RAG_B / RAG_A |
|---|---|---|
| 初始区域已混合（INITIAL_MIXED） | 66 / 67 / 67 | 114 / 117 / 117 |
| 合并错误（MERGE_ERROR） | **240** / 69 / 45 | **430** / 182 / 135 |
| 合并不足留下碎片 | 74 / 69 / 72 | 71 / 73 / 79 |
| 其他 | 41 / 27 / 26 | 70 / 46 / 46 |

- **改进几乎全部来自合并机制：** 合并错误从 240 降到 45–69（15023），从 430 降到 135–182（15041）。
- **初始区域混合是新的主要限制：** RAG 方案剩余失败中，有 29–32% 是初始区域已经混合，合并做得再好也恢复不了。
- 碎片类失败与 M2_hybrid 基本持平，说明合并阈值没有导致明显的合并不足。

## 5. 需要注意的问题

- **区域数偏多：** RAG 方案的区域数比真值实例多 30–40%，其中 13–17% 小于 50 px。这些碎区没有拉高小实例过分割（增加只有 0.006–0.016），但对 GIS 用户意味着更多需要人工合并的小面。
- **开发图并不独立：** B2 的检查点是按这两幅图的验证损失选的；τ、λ 在训练图上选。Gate 4 的新图才是真正的检验。
- **3–6 px 仍然很低**（0.12–0.22），但已经高于 M2_hybrid（0–0.03）。这一组按预注册单独报告。
