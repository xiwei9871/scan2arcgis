## 2. 模型失败的拆分（两图合计）

对 M2_hybrid 没有恢复的小实例：
- **后处理可解决：** 同一张 M2 预测距离场，换成理想种子后能恢复；
- **需要改进预测：** 理想种子也恢复不了。其中再分两种：
  - 换成官方距离场（O_GTD_ideal）后能恢复的，记为"预测场限制"；
  - 连官方距离场也恢复不了的，记为"超出分水岭重建或评价口径"。

## 3. 解读

- **3–6 px 主要必须改进预测。** 86% 的失败即使给出理想种子也无法恢复，因为预测场在单元内部没有可用的起伏（Gate 1：p > 0.5 覆盖单元全部像素）。官方距离场加理想种子可以恢复 65–79%，说明分水岭重建本身做得到，差在预测场。
- **6–10 px 和 10–20 px 是一半对一半。** 约 41–50% 的失败只需更好的种子就能解决，其余要靠更好的预测场。
- **种子规则本身仍有较大空间：** 官方距离场上，hybrid 种子达到 0.891 / 0.902，理想种子达到 0.966 / 0.980，差距 0.08。
- **M1 的边界概率作为分水岭地形比 M2 的距离头更好，前提是种子已知。** O_M1P_ideal 为 0.823 / 0.783，O_M2D_ideal 为 0.740 / 0.714。这与 Gate 2 不矛盾：Gate 2 比较的是"种子也要自己预测"的情况，M2 的距离头主要帮的是种子生成。这一点提示，改进可以考虑"距离头生成种子 + 边界概率作为分水岭地形"的组合，但这需要新的预注册，本轮不做。
- **上限的乐观程度：** 理想种子也携带了"每个实例恰好一个种子"这一数量信息，所以"后处理可解决"的比例是乐观估计，任何实际可行的种子规则都达不到。
