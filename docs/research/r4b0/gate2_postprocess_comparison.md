# R4-B0 Gate 2：M1 与 M2 后处理的公平比较（2026-10-29）

规则：预注册 gate2（提交 `f82b2c87be13929aea7e055d18ec872df9c2d263`）。每种方法只运行一次。
结果：`experiments/R4B0/gate2/gate2_comparison.json`；复现一致性检查：`gate2_reproduction_check.json`。
所有方法使用相同的预测文件、有效区和评价代码（`r4a2_2_eval.instance_metrics` / `boundary_metrics`，未修改）。

## 结论

**M2 的距离输出头有独立价值，不能用更简单的 M1 替代。** 两幅图上，M2_hybrid 的小实例召回都比任何 M1 方案和 M2 自身的"概率派生距离"对照组高 0.033–0.080，过分割也更低。按预注册规则判定为 `M2_HEAD_HAS_VALUE`。

## 2. 预注册判定

| 判定项 | 结果 |
|---|---|
| 拓扑保护（过分割 ≤ M2_hybrid + 0.03，两图都要满足） | M1、M2_oldseed、M2_hybrid 通过；M1_DD_oldseed、**M1_DD_hybrid**、**M2_PD_hybrid** 不通过（过分割 0.17–0.22） |
| M2 距离头有独立价值（两图上 M2_hybrid 都比 M1_DD_hybrid、M2_PD_hybrid 中较高者高至少 0.02） | **是** |
| M1 达到或超过 M2（两图上 max(M1, M1_DD_hybrid) ≥ M2_hybrid − 0.01） | 否 |
| **结论** | `M2_HEAD_HAS_VALUE` |

**判定中的一个口径问题：** 按预注册的写法，未通过拓扑保护的方法不参与比较。这次两个对照组都没通过，"距离头有价值"这一项因此在程序里自动成立。我把不考虑拓扑保护时的原始差值也列出来，结论不变：

| M2_hybrid 减去 | 15023 | 15041 |
|---|---|---|
| M1_DD_hybrid | +0.038 | +0.060 |
| M2_PD_hybrid | +0.055 | +0.080 |
| M1（冻结分水岭） | +0.033 | +0.073 |

所以即使不看拓扑，M2_hybrid 也在两幅图上都高出 0.02 以上。

## 3. 解读

- **距离头的价值来自"同一网络内"的比较。** M2_PD_hybrid 和 M2_hybrid 用的是同一个 M2 网络、同一套种子与分水岭，只是距离场一个从边界概率推出来，一个由距离头直接预测。后者召回高 0.055–0.080，过分割低 0.13，说明距离头学到了概率阈值化得不到的信息。
- **从边界概率派生距离会过分割。** M1_DD_hybrid 和 M2_PD_hybrid 的区域数都比真值实例数多出 30% 左右，过分割 0.17–0.22。原因是二值化后的边界在弯曲处和断续处产生许多小的距离极大值，hybrid 种子会把它们都当成种子。
- **增益主要在 6–10 px 和 10–20 px。** 3–6 px 组所有方法都几乎为 0。这与 Gate 1 一致：窄单元内部全被边界带覆盖，没有距离场或种子规则能补救。
- **M1 冻结分水岭的过分割最低（0.06），但欠分割和吞并更多。** 它在简单性和拓扑上占优，但召回比 M2_hybrid 低 0.03–0.07，按预注册规则不能替代 M2。

## 4. 复现一致性

Gate 2 从保存的 float16 概率和距离文件重新运行后处理。R4-A2.2 当时是在内存里对 float32 网络输出做的后处理。两者在少量像素上的分水岭结果不同：

- 区域划分的一致率为 0.9996–0.99998（逐区域多数匹配）；
- 15041 的 M1 区域编号有平移，所以"编号逐像素相同"的比例只有 0.73，但区域划分本身一致率为 0.9996；
- 小实例召回与 R4-A2.2 报告相差不超过 0.001（例如 15023 M2_oldseed 为 0.5173 → 0.5163），过分割完全相同。

因此 Gate 2 中的 M1、M2_oldseed、M2_hybrid 与 R4-A2.2 基线可以直接对比，差异在第三位小数以内。
