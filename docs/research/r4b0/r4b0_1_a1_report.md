## 2. 解读

- 换地形是一个小幅、稳定的改进：两幅图方向一致，没有任何拓扑代价，边界 F1@1 也提高了 0.025–0.033。但幅度不到预注册的门槛，所以不作为 R4-B1 的固定候选。
- 改进集中在 10–20 px（+0.017 到 +0.030），3–6 px 完全没有变化。这符合 R4-B0 Gate 3 的预期：窄单元缺的是种子，不是地形。
- R4-B0 Gate 3 中，"M2 预测场 + 理想种子"比"M1 概率 + 理想种子"低约 0.08。这次只换地形得到的增益只有 0.012，说明那 0.08 的差距大部分来自种子，而不是地形。
