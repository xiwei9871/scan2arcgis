# R4-B1T Gate 0：统一宽度与评价口径（2026-10-29）

起点：`37b5f887577bde8cae41cc18e8e48c8badc11d46`。
代码：`experiments/R4B1T/r4b1t_width.py`（今后唯一的宽度实现）、`r4b1t_gate0.py`；测试：`tests/r4b1t/test_r4b1t_width.py`（3 项）。
结果：`experiments/R4B1T/gate0/width_reconciliation.json`。只读标签，没有用到任何模型输出。历史数据和报告不改。

## 1. 统一口径

| 项 | 定义 |
|---|---|
| 实例 | 官方 `instance.npy`：同一 geo_A 单元在 GeoTIFF 网格上的 4 连通分量；ID = 值 + 1 |
| 有效区 | `ignore.npy == 0` 且 `unit.npy >= 0`，与 `r4a2_2_eval.load_ref` 相同 |
| 面积 | 实例在有效区内的像素数 |
| 小实例 | 200 ≤ 面积 < 20000 |
| 宽度 | 实例在有效区内的掩膜，外扩 1 px 后算 DIST_L2（mask 5）距离，宽度 = 2 ×（最大距离 − 0.5） |
| 分组 | [3, 6)、[6, 10)、[10, 20)；另列 < 3 和 ≥ 20 |

**量化特性（单元测试已固定）：** 轴向直条带宽 k px 时，奇数 k 读作 k，偶数 k 读作 k − 1。因此 [3, 6) 组对应真实宽 3–6 px，[6, 10) 对应 7–10 px，[10, 20) 对应 11–20 px。我保留这个公式不改，因为它就是 R4-B0 Gate 1–3 的公式，改了会让之前所有分宽度结果失去可比性。

## 2. 历史版本对照

| 版本 | 公式 | 范围 | 与统一口径的关系 |
|---|---|---|---|
| H1：R4-B0 开始前的预检 | 2 × 最大距离（没有 −0.5） | 全网格 | 宽度系统性大 1 px，大量实例从 3–6 移到 6–10 |
| H2：R4-A2.2 的 `width_old` | 2 × 实例内到 UB 的最大官方距离 + 1 | 有效区 | 另一种量法，作为旧口径并列保留 |
| H3：R4-B0 Gate 1–3 的 `width_own` | 统一公式 | 有效区 | **完全一致** |
| H4：R4-B1 Gate 1–2 的 `width_own` | 统一公式 | **全网格**（没有用有效区） | 只在有效区边缘差几个实例 |

### 小实例分组数量

| 版本 | 训练图 3–6 / 6–10 / 10–20 | 15023 + 15041 3–6 / 6–10 / 10–20 |
|---|---|---|
| **统一口径** | **44 / 252 / 735** | **115 / 506 / 1072** |
| H1 预检 | 15 / 199 / 751 | 53 / 395 / 1197 |
| H2 R4-A2.2 | 40 / 218 / 730 | 103 / 433 / 1108 |
| H3 R4-B0 | — | 115 / 506 / 1072（逐图：15023 为 34 / 184 / 407，15041 为 81 / 322 / 665） |
| H4 R4-B1 | 43 / 256 / 737 | 113 / 508 / 1075 |

- **早期预检与 R4-B0 的差异全部来自 H1 少了 −0.5。** 例如 15023 的 3–6 px 组，H1 为 16 个，统一口径为 34 个。R4-B0 的报告用的是统一口径，没有受影响；只有 R4-B0 开始前那次讨论里引用的数字（16 / 131 / 456）属于 H1。
- **R4-B1 Gate 1–2 与统一口径的差异来自有效区。** 10 幅训练图中有 7 个小实例的一部分落在有效区外：全网格下面积 ≥ 200，有效区内不足 200，所以统一口径下不算小实例。两者共同的实例中，99.2–100% 落在同一宽度组。R4-B1 报告中的 43 个 3–6 px 实例在统一口径下是 44 个，差异在报告结论的精度以内。
- 实例总数：10 幅训练图中有 9 幅，有效区内的实例数与全网格相同；07089 少 1 个（该实例完全落在有效区外）。
