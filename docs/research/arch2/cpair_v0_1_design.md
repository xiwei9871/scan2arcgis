# C-PAIR V0.1 修订设计（ARCH-2 任务一，2026-10-30）

依据：ARCH-1 总报告（`29c1a9c`）、评审意见、公共细分勘误（`35eb8d5`）、指标定义（`6557191`）。
本文件取代 ARCH-1 Gate 5 中的 C-PAIR 设计。原文件保留不改。

## 0. 相对 ARCH-1 设计的修改

| 项 | ARCH-1 Gate 5 | 本版 |
|---|---|---|
| 证据独立性 | 把错误 φ < 0.3 写成"相互独立" | 只说明三项特征**有互补性**，不认定统计独立；是否能触发软保护，由联合判别实测的精度、召回、误保护率决定 |
| 宽度证据 | 视为独立于 B2 | 宽度来自 B2 线对，**受 B2 误差影响**，与 B2 边界强度不是独立来源 |
| 候选生成 | 要求两条已存在、近似平行的 B2 线段 | 允许线段不完整、局部偏移和断续；补线必须受几何和外观约束 |
| 参数 | 写死间距 2–12 px、方向差 25°、重叠 15 px、缺口 4 px | 全部视为**待预注册参数**，在 ARCH-2 预注册中固定一组，只在训练图上验证 |
| 公共细分 | ARCH-1 的 `graded()`（去重有缺陷） | 区域级去重 `arch2_subdivision.graded_region`（cover 0.9，size 1.5） |
| 评价 | 只看 Oracle A 上限和合并后召回 | 候选生成与候选判别**分开评价**；一对一匹配；报告精度、召回、误报率、FDR、基率、误保护率和存活率，以及实例数和置信区间 |

## 1. 流程

```
B2 边概率 ──► 线图（骨架、方向、端点、交点）──► 线对候选生成 ──► 候选判别（三特征）──► 状态
                                                                      │
B2 过分割 ──► 区域级去重的公共细分（候选加入） ◄──────────────────────┘
                     │
                     ▼
              统一区域图（冻结 τ = 0.45 的中位数合并 + 软保护代价）──► 最终区域 ──► 决策记录去向 ──► GIS
```

## 2. 线图（只用预测）

- 线响应 = B2 像素强度 b（`r4c0_rag.strengths`）> θ_line，再骨架化。
- 局部方向：线响应的结构张量（σ 1.5 / 2.5 px，与 ARCH-1 线宽代码相同）。
- 节点：端点（骨架邻居数 = 1）、交点（≥ 3）。线段：两个节点之间的骨架链。
- 线段属性：长度、平均强度、方向序列、两侧 1–3 px 的颜色均值（非墨线像素）。

## 3. 候选生成

**基本单元：** 两条线段在一段走向范围内相对。

1. **配对：** 对线段 A 上每个骨架点，沿法线两侧在 [d_min, d_max] 内搜索另一条线段 B 上的点，要求局部方向差 ≤ Δθ。连续配对的点构成一个"相对区段"；区段长度 ≥ L_min 才保留。
2. **不完整与断续：** 一侧线段在不超过 g_max 的长度内缺失时，仍沿另一侧的走向延伸配对，缺口处的间距用两端间距线性插值。缺口只能补在以下位置：缺口两端的间距差 ≤ 2 px，且缺口内中线附近的颜色与区段内一致（Lab 色差 ≤ ΔE_gap）。这样可以避免把任意两条墨线连起来。
3. **局部偏移：** 配对容忍 ±1 px 的法线方向偏差（ARCH-1 Gate 0：B2 严格位置覆盖明显低于 1 px 容差）。
4. **尖灭：** 相对区段的间距降到 < 2 px 的一端视为尖灭，候选在该处截止；一端开口也允许。
5. **掩膜：** 两条线之间、沿法线的像素（包括插值补齐的缺口段），作为候选区域。宽度序列 = 每个骨架点处的间距。
6. **去重：** 同一组像素被多个区段覆盖时，只保留面积最大的那个；与 B2 过分割已有区域重合的候选，在公共细分时由区域级去重处理。

生成器只输出候选，**不判断真假**。对每个候选标出三类倾向的原始证据，交给判别模块。

## 4. 候选判别（复用三项特征，联合使用）

| 特征 | 计算 | 来源 |
|---|---|---|
| s_edge | 两侧线上 B2 强度中位数，取较弱一侧 | B2 |
| s_colour | 中线 ±1 px 非墨线像素与两侧邻居的 Lab 色差，取较小值 | 图像 |
| s_width | 宽度序列的中位数 | 由 B2 线对推出（**不独立于 B2**） |

- **联合规则：** 只用一种简单、可解释的形式：三项都超过各自阈值时为 PROTECT_SOFT；颜色和宽度都低于"墨带阈值"时为 MERGE；其余为 UNCERTAIN。每项特征最多两个阈值（保护阈值、墨带阈值），全部只在训练图上确定。
- **准入条件：** 只有联合规则在训练图上的误保护率（被保护候选中墨带的比例）≤ 0.30 时，PROTECT_SOFT 才在合并中生效；否则全部降为 UNCERTAIN，并记录这一结果。
- 不使用：邻居数（过拟合）、局部线宽（ARCH-1 Gate 3 不合格）、M1/M2（与 B2 高度相关）。

## 5. 与 RAG 的联动

- 公共细分：PROTECT_SOFT 和 UNCERTAIN 候选通过 `graded_region` 加入细分；MERGE 候选不加入，只写入决策记录。
- 合并：保持冻结的中位数代价和 τ = 0.45。对与 PROTECT_SOFT 候选相邻的边，代价加 λ_p（软保护：更难被合并，但不禁止）。λ_p 只在训练图上从预注册的小网格中选一次。
- 决策记录（`arch1_decision_store.py`，已验证几何可逐像素还原）：每个候选都记录掩膜、中线、宽度序列、三项证据、状态及原因、合并前的候选 ID、合并后的去向和是否存活。

## 6. 输出

在 R4-C0.1b 不读标签的导出基础上，新增：
- 面图层字段：`decision_state`、`evidence`、`cpair_id`；
- 复核图层：被合并掉的 PROTECT_SOFT / UNCERTAIN 候选，保留原几何、证据和最终去向。
