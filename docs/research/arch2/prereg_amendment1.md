# ARCH-2 预注册修订 1（项目负责人要求的 P0 修订，2026-10-30）

本文件和 `experiments/ARCH2/arch2_prereg_amendment1.json` 在任何 ARCH-2 实验运行之前提交。原预注册 `experiments/ARCH2/arch2_preregistration.json`（`ad78e1d`）保持不变；两者不一致时，以本修订为准。

## 修订对照

| 项 | 原预注册（`ad78e1d`） | 修订后 |
|---|---|---|
| **P0-1 暴露图是否参与算法选择** | 暴露图 Gate 2 误保护率 > 0.30 时，Gate 3 关闭软保护 | 是否启用 PROTECT_SOFT **只由训练图决定**，写入 `arch2_freeze.json`。暴露图 Gate 2 只判 PASS / FAIL，不改变 V3 的运行方式。Gate 2 失败时，冻结的 V3 照常运行用于失败归因，ARCH-2 总体判为 FAIL。不存在"关闭保护后算较弱通过"的情况 |
| **P0-2 Gate 1 门槛** | Oracle A ≥ 0.65，且比 B2 高 0.10 | 训练图合并 ≥ 0.65（B2 基线 0.4545）；暴露图合并 ≥ 0.74（B2 基线 0.6438）；逐图也要满足：13014 ≥ 0.7623（0.6623 + 0.10），15076 ≥ 0.7265（0.6265 + 0.10）。每幅图的区域数 ≤ 只用 B2 时的 3 倍。训练图每幅只有 0–9 个 3–6 px 实例，逐图报告，但只按合并值判定 |
| **P0-3 缺失颜色证据** | 未规定 | 候选中线 ±1 px 的非墨线像素少于 5 个，或任一侧邻居环带的非墨线像素少于 5 个时，颜色差记为**缺失**。任一特征缺失的候选一律 UNCERTAIN，既不 PROTECT_SOFT 也不 MERGE；缺失**不按 0 处理** |
| **P0-3 误保护口径** | 只约束墨带误保护率 | 同时报告：墨带误保护、偶然窄带误保护、被保护候选的总 FDR。训练图选参数时，除墨带误保护率 ≤ 0.30 外，**另加总 FDR ≤ 0.50**（这一条由我补充，不是您原文中的要求）。暴露图 Gate 2 在每幅图上和合并后都要满足：墨带误保护率 ≤ 0.30、FDR ≤ 0.50、被保护真实窄候选召回 ≥ 0.30 |
| **P0-3 分开统计** | — | 候选检出、分类精度、合并后的地质面召回、被保护候选的存活率，分别统计 |
| **逐图判定** | 未明确 | 13014 和 15076 始终分开报告、分开判定；合并值不能覆盖某一幅图的失败 |
| **置信区间的局限** | 未说明 | Wilson 区间和配对 bootstrap 都假设实例相互独立。同一幅图内的实例在空间上相关，而且暴露图只有两幅，所以这些区间会低估真实的不确定性，结果也不能外推到其他 GSJ 图式 |
| **V2 定义** | "对全部非 MERGE 候选做软保护（不做判别）"——这句话本身矛盾，MERGE 来自判别 | V2 = 对**全部**候选做软保护，完全不做判别 |
| **Gate 3 逐图** | 未明确 | Gate 3 的各项条件在训练图合并值上和每幅暴露图上分别满足；暴露图要求合并后的配对 bootstrap 下限 > 0，并逐图报告 |
