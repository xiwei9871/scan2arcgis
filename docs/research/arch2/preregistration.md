## 2. 参数

**现在就固定、不调的**（来自设计，不来自任何测量）：

| 参数 | 值 |
|---|---|
| 线响应阈值 | 0.5 |
| 线对间距 | 2–12 px |
| 最大方向差 | 25° |
| 最小相对区段长度 | 15 px |
| 最大缺口 | 4 px；缺口两端间距差 ≤ 2 px，且颜色差 ≤ 10 |
| 法线方向容差 | ±1 px |
| 尖灭判定间距 | < 2 px |
| 公共细分 | 区域级去重，cover 0.9、size 1.5 |

**只在训练图上选择一次的：**
- **三项特征的阈值：** 每项特征一个保护阈值、一个墨带阈值。保护阈值取训练图真实窄候选的第 10 / 20 / 30 百分位（3 × 3 × 3 = 27 种组合）；墨带阈值取墨带候选的第 50 / 70 百分位（2 × 2 = 4 种组合）。
- **选择规则：** 在训练图误保护率 ≤ 0.30 的组合中，选被保护真实窄候选召回最高的。如果没有任何组合满足，就关闭 PROTECT_SOFT，所有候选都按 UNCERTAIN 处理，并如实报告。
- **软保护 λ_p：** 网格 {0.05, 0.10, 0.20, 0.30}。在训练图过分割增加 ≤ 0.03 的前提下，选合并后 3–6 px 召回最高的。

## 3. 四个 Gate

| Gate | 测什么 | 通过条件 | 不通过时 |
|---|---|---|---|
| **1 候选生成** | 3–6 / 6–10 px 实例的检出率（一对一匹配，IoU ≥ 0.3）、定位 IoU、各类候选数、分级细分后的 Oracle A / B、区域数、时间、内存 | 训练图和暴露图**都满足**：3–6 px Oracle A ≥ 0.65，且比只用 B2 时至少高 0.10（B2 基准：训练 0.45，暴露 0.64）；每幅图区域数 ≤ 只用 B2 时的 3 倍 | 停止 ARCH-2，报告失败在检出还是定位 |
| **2 候选判别** | 三类候选的基率；所选联合规则的精度、召回、误报率、FDR、墨带误保护率，均附 Wilson 95% 置信区间，逐图报告；单特征 AUC 只作参考 | 暴露图墨带误保护率 ≤ 0.30，且被保护真实窄候选的召回 ≥ 0.30 | Gate 3 照常运行，但关闭 PROTECT_SOFT，并报告失败 |
| **3 RAG 软保护联动** | 四个方案：V0 冻结 RAG；V1 只加候选；V2 候选 + 对全部非 MERGE 候选做软保护；V3 候选 + 判别 + 只对 PROTECT_SOFT 软保护。指标：分宽度召回（附实例数和置信区间）、暴露图上 V3 − V0 的配对 bootstrap 区间、存活率、失败分解、大实例召回、过分割、伪碎片、区域数、灾难性合并 | 训练图和暴露图**都满足**：3–6 px 召回提高 ≥ 0.10；6–10 px 下降不超过 0.02；总召回下降不超过 0.01；大实例召回下降不超过 0.02；过分割增加 ≤ 0.03；伪碎片增加 ≤ 25%；无灾难性合并 | 报告 V1 / V2 / V3 中从哪一步开始失去收益（生成、保护还是判别），不重调 |
| **4 输出回归** | 在 13014、15076 上对 V0 和 V3 做 9 项导出检查；被合并的候选能从决策记录逐像素还原；预测和导出代码中不使用 `ignore.npy` 或任何由标签生成的掩膜 | 全部通过 | — |

**不确定性：** 训练图上只有 44 个 3–6 px 实例，所以训练图按点估计判定，同时报告置信区间。暴露图上有 160 个，要求 3–6 px 的配对 bootstrap 下限 > 0。

**总体成功：** Gate 1、3、4 通过，且 Gate 2 通过。若 Gate 2 未通过、但关闭保护后 Gate 3 仍通过，记为较弱的结果并单独说明。

## 4. 风险与停止规则

| 风险 | 预计表现 | 处理 |
|---|---|---|
| 线对检出率低：严格位置下只有 7–18% 的窄层两侧被 B2 覆盖 | Gate 1 的 Oracle A 达不到 0.65 | 在 Gate 1 停止，报告检出失败 |
| 墨带误保护：宽度 < 6 px 的候选中，墨带数量约是真实单元的 7.5–12 倍 | Gate 2 误保护率 > 0.30 | 关闭软保护继续 Gate 3，结果标为较弱 |
| 软保护力度不够：完美候选在冻结合并下仍有 34–88% 被吞并 | Gate 3 的 V2 / V3 收益不足 | 报告是哪一步失去收益 |
| 伪碎片增加 | 伪碎片增加超过 25% | Gate 3 不通过 |
| 训练图上过拟合 | 暴露图结果明显差于训练图 | 两组图分开报告，参数只在训练图上选 |
