# 04 地质专业后处理（T3）

代码 `experiments/STITCHVECTOR/ocr_poc01/geo_postprocess.py`、`fusion_eval.py`；结果 `results/fusion_comparison.csv`、`geological_code_errors.csv`、`legend_dictionary.json`。真值仍为 `AGENT_DRAFT`。

**后处理只产生候选和理由，不改写 OCR 原文。** 下表打分用"建议值（没有建议时用原文）"，衡量的是人工复核时看到的首选候选。

**披露**：纠错规则和融合规则是看过本轮各引擎错误之后写的，属于探索性结果，没有预注册。它们在同一份真值上打分，存在过拟合风险，必须在别的图上验证。

## 1. 两级知识

| 级别 | 内容 | 是否用 U2 信息 |
|---|---|---|
| GENERIC | R1 时代前缀后紧跟的数字是下标（Ar2E→Ar₂E、J3t→J₃t）；R2 地层范围必须由老到新，`E-O / C-O / €-O / 6-O` 都不合法，只有 `Є-O` 合法；R3 代号末尾 `-0` 是字母 O | 否，适用于任何中国地质图 |
| LEGEND | 从 U2 图例自动提取的代号词典；字母/数字混淆（z/s/i/u/l/1 代替丢失的下标、Pu 代替 Pt₁）只生成候选，**词典里恰好命中一个**才作为建议 | 是 |

图例词典由三个引擎的图例 OCR 投票得到（至少两个引擎支持，直接读数权重高于推测变体）：`Ar₂E、C-P、HtL、Jxd、N-Q、T、Є-O`，共 7 条。其余 7 行图例三个引擎读不一致（如 `Jy / J / Js`、`PuD / PD / PtiD`），记为 unresolved，没有进词典。`Jxd` 实际应为 `J₂d`，词典也会出错。

## 3. 防止词典过拟合（T3.4）

| 口径 | 地层代号完全正确 |
|---|---|
| 原始 OCR（PaddleOCR 端到端） | 0.491 |
| + 不含 U2 信息的通用规则 | 0.800 |
| + U2 图例词典 | 0.800（没有额外提升） |
| 跨图泛化（不用 U2 词典，换一张图） | **NOT_EVALUATED**：本轮没有 u3 或 GSJ 的文字真值 |

U2 词典没有带来提升：它只有 7 条，能命中的代号通用规则已经改对了；剩下的错误都是词典不收录或读法有歧义的代号。词典命中率不能当作 OCR 准确率。

## 4. 剩余错误（方案 6b，12/55）

| 真值 | PaddleOCR | Surya 复读 | 原因 |
|---|---|---|---|
| J₃t | J3t | J₃ₜ | Surya 把 t 也当成下标；投票选错 |
| Pt₁L ×3 | PtL / PuL / 漏检 | PtuL / PtiL | 下标 ₁ 丢失或与 t 粘连；词典无 Pt₁L |
| J₁y ×2 | Jiy / Jy | Jiy / Jy | ₁ 读成 i 或丢失；J₁y/J₂y 都可能，歧义 |
| J₂y | Jhy | Jy | 读错 |
| Ar₂J | ArJ | Ar2J | 投票选了 PaddleOCR 读数 |
| J₂d | Jed | Jed | ₂ 读成 e |
| Pt₁D ×2 | PuD | PuD / Pt₄D | Pt₁ 粘连成 Pu |
| T | 漏检 | — | 检测问题 |

常见混淆（T3.2）：`Є`→`€ / C / E / 6`；下标 `₂`→`2 / z / e`、`₁`→`i / u / 1` 或丢失；`O`→`0 / o`；组合代号被拆分或与相邻符号合并（`40` 前的产状符号读成 `K / X / £`）。每个对象的候选列表和理由见 `geological_code_errors.csv` 的 `candidates_4b` 列。
