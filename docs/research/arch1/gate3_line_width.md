# ARCH-1 Gate 3：墨带截面线宽验证（2026-10-30）

判据：`experiments/ARCH1/arch1_criteria.json` 的 gate3（`dc6469a`，运行前提交）。只运行一次。
代码：`experiments/ARCH1/arch1_linewidth.py`（估计器，只读图像）、`arch1_gate3.py`（验证）。结果：`experiments/ARCH1/gate3/gate3_line_width.json`。
官方线只用于挑选评价样本和给区域分类，从不作为估计器的输入。

## 结论：**LINE_WIDTH_ESTIMATOR_NOT_QUALIFIED**

5 项检查中 3 项未通过。按预注册规则，我没有调整阈值重跑。

| 检查 | 要求 | 结果 | 通过 |

| (a) 官方接触线上的可靠样本：每图中位数在 0.8–3.5 px，图间变异系数 ≤ 0.35 | — | 每图中位数 1.42–2.23 px，变异系数 0.117 | 是 |

## 失败原因

1. **约 1 px 的细线会被系统性高估：** 1 px 线估成约 1.4 px，0.75 倍缩放后线宽降到约 1.5 px，也落入这一区间。这是截面积分在采样极限附近的分辨率问题，与 R4-B0.1 C1 失败的原因相似，但这次只出现在最细的一档。
2. **真实地图上，可靠样本太少：** 每幅图只有 0.7–22% 的骨架样本被判为可靠。最主要的标记是"靠近交点或端点"（54–93%）、"6 px 内有第二条线或深色填色"（32–73%）和"对比度低"（25–70%）。地质图上的线条交织得太密，适合测宽的干净线段很少。
3. **因此判别检查实际上没有足够的样本：** 1,879 个窄区域中，1,733 个在周围 10 px 内找不到足够的可靠线宽样本（不少于 3 个），AUC 只基于 146 个区域。在这些区域上，"区域宽度 ÷ 局部线宽"的区分能力（0.68）还不如单用区域宽度（0.78）。

## 对架构的含义

- 在 GSJ 这类密集的地质图上，**用"局部印刷线宽"区分墨带和窄地层的方案，目前不成立**。C-PAIR 不能依赖它。
- 线宽估计本身对 1.5 px 以上的孤立线是准的，图间也稳定（a 项通过）。它可以保留为一项工具，用于估计整幅图的印刷线宽，例如为中国图的尺度归一提供参考，但不能用于逐个区域的判别。
- 本轮不再尝试第三种线宽方法。墨带判别改为依靠 Gate 1 中已证明相互独立的组合证据：B2 边界强度、颜色差和预测宽度。
