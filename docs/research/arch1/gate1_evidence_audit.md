## 3. 主要发现

1. **边界层面的问题基本已经解决：** 在 T2（防止错误合并）和 T4（大单元完整性）上，B2 边界强度的 AUC 是 0.97–0.99，M1、M2 的边界概率也有 0.95–0.98。错误合并和大单元被切碎，不是因为缺少证据。
2. **难点集中在小区域（T1、T3）：** 单个特征的 AUC 最多约 0.85–0.89。要保留 95% 的真实小单元，误报率仍有 49–66%，单靠一个特征做不到可靠区分。
3. **对 ≤ 6 px，颜色差与 B2 边界强度一样有效**（0.850 / 0.857 对 0.877 / 0.849），而且训练图和暴露图之间更稳定。B2 边界强度在暴露图上下降更多，说明它受样本内偏差影响。
4. **邻居数严重过拟合：** 训练图 0.104，暴露图 0.280。这类证据不能使用。
5. **墨线占比单独使用不够强：** AUC 只有 0.29–0.34（低值 = 真实单元），符合 ARCH-0 D1 的发现：墨带外观在两类之间重叠。

## 4. 证据独立性（按错误相关性实测，T1 合并两组图幅）

| 特征对 | 所属证据组 | 错误 φ | 错误 Jaccard | Spearman |
|---|---|---|---|---|
| B2 边界强度 / 颜色差 | E-LINE / E-APP | **0.261** | 0.427 | 0.425 |
| B2 边界强度 / 宽度 | E-LINE / E-GEO | 0.177 | 0.391 | 0.263 |
| 颜色差 / 宽度 | E-APP / E-GEO | 0.178 | 0.417 | 0.168 |
| B2 边界强度 / 墨线占比 | E-LINE / E-INK | 0.247 | 0.463 | −0.102 |
| 颜色差 / 墨线占比 | E-APP / E-INK | 0.288 | 0.520 | 0.131 |
| B2 边界强度 / M1 边界概率 | E-LINE / E-REG | 0.130 | 0.378 | −0.131 |
| **M1 / M2 边界概率** | E-REG / E-REG | **0.657** | 0.742 | 0.826 |
| **M2 最大距离 / 宽度** | E-REG / E-GEO | **0.538** | 0.641 | 0.655 |

- 按预注册标准（错误 φ < 0.3 算"实际上独立"），**B2 边界强度、颜色差、宽度三者两两独立**，可以作为不同来源的证据组合使用。
- **M1 与 M2 高度相关**（φ 0.66），只能算一项证据。**M2 最大距离和预测宽度**测的几乎是同一个东西（φ 0.54），也只能算一项。
- 墨线占比与颜色差的 φ 为 0.288，接近门槛，应谨慎地当作半独立证据。

## 5. 对架构的含义

- 合并阶段（T2、T4）已经有可靠的边界证据，不是下一步重点。
- 伪碎片判别（T1、T3）需要**组合** B2 边界强度、颜色差和宽度三类相互独立的证据；单个阈值无法同时做到高召回和低误报。
- M1 和 M2 不应作为与 B2 独立的证据重复计分；"M2 距离"与"宽度"只计一次。
- 邻居数在样本内过拟合，不使用。
