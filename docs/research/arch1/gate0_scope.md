## 1. ARCH-0 三项诊断的口径说明

| 诊断 | 正确的解读 |
|---|---|
| D1 墨带分类 | 用预先定义的阈值（≥ 80% 像素离交界 ≤ 1.5 px，且 ≥ 60% 在墨线上）得到的**代理分类**，不是独立的墨带真值标注 |
| D1 中 7.5:1 到 12:1 的比例 | 这是**本次 RAG 候选集**中、宽度 < 6 px 的区域里伪碎片与真实小单元之比，不是 GSJ 地质图中真实地层的基率 |
| D2 的 0.59 | 三模型叠加后 3–6 px 的 **Oracle A 乐观上限**；更严格的 Oracle B 只有 0.50 |
| D2 的合并时间 | 只包括区域图构建和合并，不含推理、过分割、导出，**不是端到端时间** |
| D3 的边界覆盖 | 只说明 B2 对真实交界有响应，**不等于能自主检出线对**；"两侧"是按官方相邻实例分的，属于真值辅助 |

**更正后的结论：** B2 对窄地层的边界有可利用的响应，但大多在 1 px 范围内而不是恰好在边上。按严格位置，只有 7–18% 的窄实例两侧都被 B2 覆盖良好。ARCH-0 中"B2 已经看到了大部分窄层的两侧边界"的说法过于乐观，以本表为准。这也说明 C-PAIR 必须容忍约 1 px 的位置偏差。
