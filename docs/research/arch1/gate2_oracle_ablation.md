## 2. 解读

1. **只提供窄候选不够，还必须保护它们。** O_NARROW_CANDIDATES 把 ≤ 6 px 的初始区域上限提高到 1.00，但合并后召回只有 0.48 / 0.44：冻结的合并规则把大部分候选又并回了邻居（合并错误从 116 增加到 137）。同时还切出了大量碎片（伪碎片 11,074 / 19,003）。和完美的合并关系组合后，≤ 6 px 和 6–10 px 都达到 1.00。这直接说明：**C-PAIR 必须同时提供候选和保护（PROTECT），只生成候选会被合并吃掉。**
2. **合并关系是最有价值的单项证据：** 完美合并关系让总召回从 0.89 / 0.75 提高到 0.97 / 0.91，6–10 px 提高 0.20 / 0.25，伪碎片减少约 80%。剩下的失败只有"初始区域已混合"（64 / 140）。
3. **完美的地质单元代号几乎和完美合并关系一样好**（0.957 / 0.900）。但它主要靠"同单元强制合并"这一项；如果只用"不同单元禁止合并"（事后加的变体），收益降到 0.928 / 0.836，而且伪碎片不减少。这说明代号证据的主要价值在于判断"该合并"，而不是"该分开"。现有 OCR 只覆盖两幅开发图，这一项暂时无法实现。
4. **完美的墨带判别本身收益很小：** 伪碎片减少 50–59%，但召回只提高 0.001 / 0.010。伪碎片对小实例召回影响不大，它增加的主要是修图负担。
5. **O_CONTACT 的结果受接口限制，不能据此判断接触线证据的价值。** 把 0/1 的官方边送进现有的过分割和中位数合并后，训练图上"初始区域已混合"从 64 增加到 289，大单元召回从 0.95 降到 0.83。原因是：边界像素带内的像素对强度为 0，跨单元的区域会经由这些像素对连通。用官方边**直接**重建是精确的（R4-B2 Stage 1 修订版，10/10 一致）。这说明：**如果将来的线证据质量很高，应该直接用于切割，而不是走中位数合并。**

## 3. 预注册保留规则

规则：≤ 6 px 或 6–10 px 组提高 ≥ 0.03，或总召回提高 ≥ 0.01，或伪碎片减少 ≥ 30%，满足其一即保留。**所有单项和组合都满足，全部保留为候选。** 按价值排序：

| 证据 | 主要价值 | 能否用现有手段实现 |
|---|---|---|
| 合并关系（是否属于同一单元） | 最大：总召回、6–10 px、伪碎片 | 部分：Gate 1 中的边界强度、颜色、宽度 |
| 窄候选 + 保护 | ≤ 6 px（只在有保护时有效） | 需要 C-PAIR 和经过验证的 PROTECT 证据 |
| 地质单元代号 | 接近合并关系 | 需要训练图上的 OCR，目前没有 |
| 墨带判别 | 伪碎片减少 50–59% | 部分：Gate 1 的组合特征 |
| 接触线 | 受接口限制，结论待定 | 需要能直接切割的线证据 |
