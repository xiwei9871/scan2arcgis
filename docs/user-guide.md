# 地质图自动转换工具 - 用户指南

## 快速开始

### 前置要求

- Node.js 18+
- Python 3.12+
- pip 和 npm 包管理器

### 1. 启动后端服务

```bash
cd backend
pip install -r requirements.txt
uvicorn api.main:app --reload --port 8000
```

后端将在 `http://localhost:8000` 启动

### 2. 启动前端服务

```bash
cd frontend
npm install
npm run dev
```

前端将在 `http://localhost:5173` 启动

### 3. 访问应用

打开浏览器访问 `http://localhost:5173`

## 使用流程

### 步骤 1: 上传地质图

1. 点击上传区域或拖拽文件
2. 支持的文件格式：PNG, JPG, PDF
3. 文件大小限制：10MB

### 步骤 2: 地理配准（可选）

1. 上传后自动弹出配准界面
2. 在图像上点击添加至少3个控制点
3. 为每个控制点输入经纬度坐标
4. 点击"提交配准"

**注意**：如果图像已有地理参考信息，可跳过此步骤。

### 步骤 3: 开始处理

1. 上传完成后，系统自动开始处理
2. 实时查看处理进度和状态
3. 处理时间通常为 1-5 分钟

### 步骤 4: 下载结果

1. 处理完成后自动显示结果
2. 点击下载按钮获取 ZIP 压缩包
3. 解压后可在 GIS 软件中打开

## 输出文件说明

| 文件名 | 说明 | 格式 |
|--------|------|------|
| `contours.geojson` | 等高线 | GeoJSON |
| `boundaries.geojson` | 地质界线 | GeoJSON |
| `stratigraphy_0.geojson` 等 | 地层分区（按颜色分层） | GeoJSON |

### 在 GIS 软件中打开

**QGIS:**
1. 文件 → 添加矢量图层
2. 选择 GeoJSON 文件
3. 图层将显示在地图画布上

**ArcGIS:**
1. 需要先将 GeoJSON 转换为 Shapefile（可使用在线转换工具）
2. 添加数据 → 添加矢量图层

## 常见问题

### Q: 处理时间需要多久？
A: 取决于图像大小和复杂度，通常 1-5 分钟。高分辨率图像可能需要更长时间。

### Q: 支持哪些坐标系？
A: 目前支持 WGS84 (EPSG:4326)，即常见的经纬度坐标系。

### Q: 识别准确率如何？
A: 取决于图件质量：
- **最佳**：高分辨率扫描件（300 DPI 以上）
- **良好**：清晰的数字图像
- **有限**：低分辨率、模糊或有污损的图件

### Q: 可以处理 PDF 文件吗？
A: 可以，但需要先转换为图像。上传时会自动处理。

### Q: 为什么处理失败了？
A: 常见原因：
- 图像质量太低
- 文件损坏
- 控制点坐标错误
- 服务器内存不足

查看错误消息获取具体信息。

### Q: 如何提高识别准确率？
A: 建议：
1. 使用高分辨率扫描（300 DPI 或更高）
2. 确保图件清晰、对比度适中
3. 尽量去除背景噪点
4. 提供准确的控制点坐标（用于配准）

## 故障排除

### 问题：后端启动失败
```
解决方案：
1. 检查 Python 版本（需要 3.12+）
2. 安装依赖：pip install -r requirements.txt
3. 检查端口 8000 是否被占用
```

### 问题：前端无法连接后端
```
解决方案：
1. 检查后端是否运行（http://localhost:8000/health）
2. 检查 CORS 配置
3. 检查防火墙设置
```

### 问题：处理卡住不动
```
解决方案：
1. 刷新页面
2. 重新上传文件
3. 检查浏览器控制台错误
```
