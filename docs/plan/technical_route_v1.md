# 技术路线 V1（2026-10-27 讨论结论）

依据：`docs/audits/project_recovery_20261027/` 审计，以及《自动化技术路线重构讨论稿 V1.0》的讨论回复。状态：DISCUSSION，未授权大规模开发。

## 目标

自动识别优先 + 校准置信度 + 自动质量检查 + 少量异常复核 + 反馈学习。
目标表达为：**每类要素在风险上限 α 下的自动接受覆盖率**，α 由业务按错误代价确定；不使用统一的“95%”。

## 架构（四阶段 + 两个贯穿机制）

| 阶段 | 内容 | 基础工具 |
|---|---|---|
| S1 图幅解析 | 分块读取、图幅/图例区检测、坐标注记识别、配准 | Rasterio、GDAL、PROJ |
| S2 图例理解 | 图例项检测、OCR/VLM 结构化、图例字典 | PaddleOCR，候选 VLM |
| S3 要素识别 | 每类要素一个可插拔识别器，统一接口 `(图像块, 图例字典) → (候选几何, 类别分布, 证据)`；接触线不单独识别 | 按 E2 结果选择 |
| S4 平面图重建 | 弧段-面平面拓扑，接触线由面公共边生成，断层为约束弧段；拓扑校验；坐标转换；导出 | GEOS、OGR |

- 贯穿 A：每个要素一条质量记录（class_conf、geometry_score、topology_state、map_ood_score、p_error、decision）。
- 贯穿 B：数据集、模型、推理结果、人工修订四者版本可追溯。

## 置信度决策

1. 硬约束（拓扑、属性、坐标、图幅级 OOD、图例解析）失败 → BLOCKED/HUMAN_REVIEW。
2. 误差预测模型（输入全部软信号）→ 在独立校准集上做 isotonic / conformal 校准 → p_error。
3. 每类要素阈值由 Risk–Coverage 曲线和 α 反推；置信区间按图幅 bootstrap。
4. 生产中对自动接受结果按图幅随机抽检，持续估计实际错误率。

## 数据

- L0 现有 2 张样图回归；L1 局部精确标注；L2 少量全幅；L3 封存的独立新图幅。
- 按图幅切分，防止泄漏；人工修正只进训练，不进验证。
- 优先确认样图是否有已有国家数字化矢量，可作真值与合成数据来源。

## 实验顺序

```
D0 评估集 + 评估工具 ──> E1 现有算法复测 ──> E2 横向对比 ──> E3 置信度验证
E4 配准与导出精度（与 D0/E1 并行）
```

首个实验：E1（主要交付物为 D0 评估工具与数据规范），同时并行 E4。
