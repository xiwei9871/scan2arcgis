# 后续产品能力（已登记，暂不投入开发资源）

登记日期：2026-10-28。来源：R2 外部调研（`docs/research/r2_real_map/external_survey/external_survey.md`）。
解冻条件：系统自主语义 mIoU 在开发图上有实质提升，并通过人工验收之后。

| 能力 | 说明 | 可参考的项目 | 许可证注意事项 |
|---|---|---|---|
| 地图瓦片浏览 | 原图切成瓦片，在网页中缩放、平移浏览 | Map Warper（MIT）、GDAL `gdal2tiles` | Map Warper 可以商用 |
| 原图与矢量成果叠加 | 识别出的面和线叠在原图上显示，可调透明度，可开关图层 | Allmaps（大部分 MIT） | 避开 AGPL 包（`packages/db`、`packages/api-shared`）和 GPL 包 |
| 错误区域定位与复核登记 | 系统给出疑难区域排序列表；复核人员逐项确认、修改、登记，结果回流为评价和训练数据 | 依托 R2-D 的复核项输出；"面内代号点数为 0 或多于 1"的质检规则 | 自行实现 |

## 不做的事

- 本阶段不搭建网页服务，不做前端，不接入 Allmaps 或 Map Warper。
- 不改动当前的评价标准或诊断流程。
