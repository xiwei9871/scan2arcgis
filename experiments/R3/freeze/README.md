## 指标（`experiments/R3/eval_common.py`）

所有指标都在 R1 的工作尺度（100 dpi）上计算，线容差 1.5 px。

- **语义指标（主指标）：** 系统给每个像素输出一个地层代号字符串，`None` 表示未赋值。直接拿它和官方代号比对，评价时不做任何类别重映射。
  - 输出：像素准确率、按代号的 mIoU、IoU≥0.5 的单元数、未赋值比例、错误赋值比例。
  - 同色组单元（官方 RGB 的 ΔE<3）单独报告 IoU。
- **区域指标（评价上限）：** 沿用 R2 的 `evaluate()`，用匈牙利 1:1 映射。
- **线与拓扑：**
  - 接触线精度、召回、F1，用面边界对照官方 `geo_L` 中的接触线。
  - 断层单独评价。面边界对断层的覆盖率只作参考，不算作断层识别能力。
  - 实例召回、小实例召回（小于 5000 个工作尺度像素）、每个实例被切成的块数、邻接关系精度和召回。

**一致性检查：** 用评价时的匈牙利映射给 R1 类别命名，语义像素准确率 0.8193 / 0.6993，与区域上限 0.8194 / 0.6993 一致。

## 数据边界

- **官方数据只用于评价：** xlsx（代号、RGB）和官方矢量只能在评价脚本里读取。这些脚本的文件名以 `_eval` 或 `_ref` 结尾，或者在文档字符串中写明 `EVALUATION ONLY`。
- **预测代码不读真值：** 预测脚本的输入只能是原图、图廓和配准，以及 R1 的输出。
