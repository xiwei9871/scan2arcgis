# R3 修复轮：S1 v2 指标冻结（在任何 S1 v2 实验运行前提交）

这份记录是对 `README.md` 的补充，原有定义一条不改。所有指标的实现都在 `experiments/R3/s1v2_eval.py`，只在评价时运行。

**通用规则**
- **计分像素：** 图廓内、并且属于某个官方单元的像素，记为 `valid`。
- **尺度：** 所有指标都在工作尺度（100 dpi）上计算。

## 确定赋值与候选集

系统对每个候选区域输出两种结果之一：
- **确定代号：** 只给一个代号。
- **候选集：** 不给确定代号，而是列出若干可能的代号。候选集不计入确定赋值。

| 指标 | 定义 |
|---|---|
| `det_coverage`（确定赋值覆盖率） | 有确定代号的像素 / 计分像素 |
| `assigned_precision`（已赋值精度） | 确定代号等于官方代号的像素 / 有确定代号的像素 |
| `candidate_hit_rate`（候选集命中率） | 在只有候选集、没有确定代号的像素里，官方代号落在候选集内的比例 |
| `mean_candidates`（平均候选数） | 上述像素的候选集大小，按像素加权平均 |
| `semantic_miou`（完整语义 mIoU） | 沿用 `eval_common.semantic_scores`。候选集算作未赋值；评价时不做任何类别重映射 |
| `same_colour_macro_iou` | 同色组单元（官方 RGB 的 ΔE<3）各自语义 IoU 的平均 |

## 错误吞并

**吞并像素**的条件：该像素被确定赋予了单元 B 的代号，而它的真值是单元 A，同时满足：
- A 和 B 在官方真值里相邻；
- B 的总面积大于 A。

| 指标 | 定义 |
|---|---|
| `absorption_rate_small_units` | 小单元（官方总面积 < 10,000 个工作尺度像素）中被吞并的像素 / 小单元总像素 |
| `absorption_rate_same_colour_units` | 同色组单元中被吞并的像素 / 同色组单元总像素 |
| `same_colour_into_group_partner_rate` | 同色组单元的像素被赋成同组其他单元代号的比例（不要求相邻，也不要求对方更大） |

## 确定赋值的小单元召回

- **定义：** 小实例（面积 < 5,000 个工作尺度像素，与 `region_scores` 一致）中，至少一半像素被确定赋予了正确代号的比例。
- **分开报告两类损失：**
  - **分割损失：** R1 根本没把这个实例分成单独的区域（按评价专用的匈牙利映射，R1 覆盖不到实例的一半）。S1 无法补救。
  - **命名损失：** R1 有区域，但代号赋错了。只有这一类是 S1 能改的。
- 所以除了总召回，还单独报告 `det_small_recall_among_segmentable`，即只在 R1 能分出来的小实例里统计。

## 判定规则

不能只看总像素准确率。一个配置相对 R3-A3 算"改善"，需要同时满足：
1. `absorption_rate_small_units` 或 `absorption_rate_same_colour_units` 至少一项下降；
2. `assigned_precision` 上升；
3. `semantic_miou` 下降不超过 0.02；
4. 两幅开发图上方向一致。

**关于审核包：** 同色组的转录参考目前是 `PROVISIONAL`，用它算出的 OCR 分数单独报告，并标注 PROVISIONAL。
