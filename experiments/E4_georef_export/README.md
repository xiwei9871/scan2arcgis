# E4 配准与 GIS 导出独立精度验证

状态：DESIGN（未实施）。与 E1 并行，分别验收。尽量只用 GDAL / PROJ / OGR 的标准功能。

## 1. 目标

证明：(a) 扫描图可以被正确配准；(b) 像素坐标的矢量可以被正确变换到目标坐标系；(c) 导出的 GeoPackage / Shapefile / File Geodatabase 能被 QGIS 与 ArcGIS 正确打开，CRS、几何、属性完整。

## 2. 假设

- H1：用图廓四角 + 内部经纬网/公里网交点做 GCP，一阶或二阶多项式即可达到业务容差；TPS 只在纸张形变明显时需要。
- H2：旧系统的拟合 RMS 低估了真实误差；独立检查点误差更大。
- H3：GDAL 原生变换结果与旧系统自研求解器在同一 GCP 下一致（差异 < 0.1 像素），否则说明旧实现有错误。

## 3. 输入

- 2–3 张图（首批用 `gm1`、`gm2`）。
- 每张图：GCP（用于求解）与 ≥ 8 个**独立检查点**（不参与求解，分布于图面各处），由地质人员读取图面经纬网或公里网交点，记录像素坐标与地理坐标。格式见 `data/labels/<map_id>/checkpoints.csv`：
  `point_id, role(gcp|check), px, py, x, y, crs, source(graticule|km_grid|corner), reader_role`
- 业务方给定的位置容差（未给定前门槛为 `UNSET`）。

## 4. 方法与工具

| 环节 | 工具 | 说明 |
|---|---|---|
| GCP 写入 | `gdal_translate -gcp` 或 rasterio `GCP` | 不重采样 |
| 变换求解与误差 | GDAL GCP transformer（`-order 1/2/3`、`-tps`），Python 侧用 `rasterio.transform.GCPTransformer` | 同一变换用于检查点计算与矢量变换，保证口径一致 |
| 重采样（可选） | `gdalwarp -t_srs` | 只用于目视叠加检查，不参与误差计算 |
| 坐标系 | PROJ / pyproj：EPSG:4490（CGCS2000）、4610（西安80）、4214（北京54）及 3°/6° 高斯-克吕格投影 | 见 §6 风险 |
| 矢量变换 | 像素 → 源 CRS（GCP 变换）→ 目标 CRS（PROJ） | 线与面先按步长加密再变换，避免非线性变换下边变直 |
| 导出 | OGR（pyogrio / GDAL）：GPKG、ESRI Shapefile、OpenFileGDB | 审计环境 GDAL 3.12（pyogrio）支持三种驱动写入 |

## 6. 指标

| 指标 | 计算 |
|---|---|
| 检查点误差 | RMSE、最大误差、95 分位；单位米与图上毫米 |
| 留一法误差 | 每次去掉一个 GCP 求解，预测该点 |
| 变换一致性 | GDAL 与旧求解器差值（像素） |
| CRS 正确性 | 导出文件 CRS 与声明一致（WKT 等价比较） |
| 往返误差 | 导出后读回再反变换回像素的误差（应 < 0.01 像素量级） |
| 格式兼容率 | 三种格式 × QGIS/ArcGIS 能打开且属性完整的比例 |
| Shapefile 限制 | 字段名截断（10 字符）、DBF 编码（需写 `.cpg` 为 UTF-8）、单文件 2 GB 上限 |

## 7. 已识别风险

1. **旧坐标系之间的转换精度**：本环境 PROJ 9.5 中，西安80 / 北京54 → CGCS2000 只有“Ballpark”转换（精度未知，`accuracy = -1`），即没有可用的七参数或格网。若业务需要在坐标系之间转换，必须由业务方提供官方转换参数；否则只能在图件原坐标系中交付。E4 报告必须单列这一项。
2. **轴序**：EPSG:4490 定义为纬度在前，pyproj 需统一使用 `always_xy=True`，导出时检查。
3. **只有图廓四角注记**时，检查点不足，E4 无法给出独立误差，需要图内经纬网或公里网。

## 8. 成功标准

1. 合成已知变换的测试：误差 < 1e-6 像素。
2. 每张图报告独立检查点误差；与业务容差比较（容差未给定则 `NO_THRESHOLD`）。
3. 三种格式在 QGIS 与 ArcGIS 中打开、CRS 正确、属性完整，往返误差在数值精度内。

## 9. 失败后决策

- 检查点误差超容差：先查 GCP 读数与变换阶数；仍超限则识别成果暂不对外交付。
- GDAL 与旧求解器差异大：以 GDAL 为准，旧求解器停用。
- 坐标系转换参数缺失：交付限于原坐标系，并在质量报告中注明。
